# MAV — сервис озвучки на моделях MAI

Дата актуальности: 2026-11-08.

MAV — самостоятельный HTTP-сервис для озвучки русского текста. Работает на
моделях шлюза MAI (`api-ai.mai.ru`). Запускается одной командой, не требует
`npm install`: зависимостей нет.

## Что важно знать сразу

**Клонирования голоса нет.** Это ограничение шлюза, а не сервиса.

| Что проверено | Результат |
|---|---|
| `silero-tts` голоса | только `aidar`, `baya`, `kseniya`, `eugene`, `xenia` |
| Голос вне списка | HTTP 400 |
| Параметр референса/эмбеддинга | отсутствует в API |
| `qwen3-tts` в `/models` | есть, но для ключа недоступна (400) |
| Латиница в тексте | отбрасывается, модель русская |

Поэтому MAV делает **подбор голоса**: измеряет высоту тона (F0) и темп
референсной записи и выбирает ближайший из пяти голосов. Это честно называется
подбором, а не клоном. Настоящее клонирование требует локальной модели и GPU;
на машине разработчика GPU нет (`nvidia-smi` отсутствует).

## Возможности

| Функция | Состояние | Проверено |
|---|---|---|
| Синтез речи, 5 голосов | работает | да, живой тест |
| Длинный текст (нарезка + склейка) | работает | да, 3119 символов → 4 куска |
| Озвучка книги по главам | работает | да |
| Дубляж (STT → текст → синтез) | работает | да |
| Подбор голоса по референсу | работает | да, F0 111 Гц → aidar |
| Локальный движок Piper | код есть | **нет**, бинарника нет |
| Клонирование голоса | невозможно на MAI | — |

## Запуск

PowerShell:

```powershell
cd services\mav
copy .env.example .env
# вписать MAI_API_KEY в .env
node src/index.js
```

Открыть `http://127.0.0.1:3901`.

Ключ можно не писать в `.env`: сервис ищет `MAI_API_KEY` в окружении, затем в
`services/mav/.env` (файл не в git, создаётся вручную), затем в корне проекта, затем в
`%USERPROFILE%\Desktop\dev\.env`.

## API

Все маршруты `/api/*` требуют `Authorization: Bearer <MAV_API_KEY>`, если ключ
задан. Исключение: `GET /api/audio/:id` принимает ключ ещё и в `?key=`, потому
что тег `<audio>` не умеет отправлять заголовки.

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/health` | состояние шлюза и движков |
| GET | `/api/voices` | голоса, модели синтеза и распознавания |
| POST | `/api/synthesize` | синтез текста любой длины |
| POST | `/api/chapters` | разбить Markdown на главы |
| POST | `/api/narrate` | озвучить книгу по главам |
| POST | `/api/dub` | дубляж: распознать и озвучить |
| POST | `/api/voice-match` | подобрать голос по референсу |
| POST | `/api/analyze` | измерить F0 и темп файла |
| GET | `/api/history` | сохранённые записи |
| GET | `/api/audio/:id` | получить аудио |
| DELETE | `/api/audio/:id` | удалить запись |

Пример синтеза:

```powershell
curl.exe -X POST http://127.0.0.1:3901/api/synthesize `
  -H "Content-Type: application/json" `
  -d '{\"text\":\"Проверка синтеза.\",\"voice\":\"baya\",\"format\":\"wav\"}'
```

## Ограничения шлюза, найденные на практике

| Ограничение | Значение | Как обходится |
|---|---|---|
| Длина текста | 500 при ~900 символах | нарезка по 800 символов |
| Формат WAV | PCM16, mono, 48 кГц | склейка без ffmpeg |
| `speed` | работает, 0.8 → 9.15 с, 2.0 → 4.09 с | ползунок 0.7–1.3 |
| MP3 | работает для одного куска | при нарезке принудительно WAV |
| Латиница | отбрасывается | не обходится |

## Архитектура

```
services/mav/
  src/
    index.js    — запуск, чтение .env
    server.js   — HTTP, маршруты, защита ключом
    service.js  — синтез, книги, дубляж
    engines.js  — движки: mai (сеть), piper (локально)
    mai.js      — клиент шлюза, эталоны голосов
    text.js     — нарезка, очистка Markdown
    wav.js      — разбор, сборка, склейка WAV
    audio.js    — F0, темп, громкость
    voice.js    — подбор голоса
    storage.js  — файлы и история
  public/       — интерфейс без фреймворков
  test/         — unit, live, server, measure-voices
```

Решения, влияющие на архитектуру, записаны в ADR:

- `docs/adr/0020-mav-servis-ozvuchki.md` — сервис, отсутствие клонирования,
  подбор голоса вместо клона.

## Тесты

```powershell
cd services\mav
node test/unit.mjs      # 31 тест, без сети
node test/live.mjs      # 14 тестов, настоящий шлюз
node test/server.mjs    # 18 тестов, HTTP
node test/measure-voices.mjs  # пересъёмка эталонных F0
```

Живые тесты тратят квоту шлюза. Эталонные F0 в `src/mai.js` получены замером,
а не из документации: документации по F0 у Silero нет. Если шлюз обновит
модель, запустите `measure-voices.mjs` и обновите `VOICE_INFO`.

## Безопасность

- По умолчанию слушает `127.0.0.1`, не `0.0.0.0`.
- Тело запроса ограничено 32 МБ.
- Статика отдаётся только из `public`, выход за пределы папки запрещён.
- Ключ MAI не попадает в ответы API и в интерфейс.
- `.env`, `data/`, `voices/` не коммитятся.

## Что осталось

1. Локальный движок Piper: код есть, бинарник и модели не установлены.
   Проверить на машине с GPU или на CPU с `ru_RU-*` моделями.
2. Настоящее клонирование: требует отдельной модели (XTTS, F5-TTS) и GPU.
   На текущей машине невозможно.
3. Подгонка длительности сегментов при дубляже: нужен ffmpeg для
   растяжения времени. Сейчас сегменты озвучиваются подряд.
4. Публикация в `crruton/MAV`: репозиторий ещё не создан (GitHub API отдаёт
   404), токена в окружении нет.
