# Набор сценариев (eval)

20 типовых задач MAI с проверяемым результатом (Q5, ADR 0082): 10 «Код»
(исправить ошибку по тесту, реализовать функцию, написать тесты,
переименование по проекту, починить JSON, собрать TODO, объяснить без правок,
убрать дублирование, флаг командной строки, раздел README) и 10 «Задача»
(сводка по CSV, Excel с итогом, отчёт Word, презентация, PDF, извлечь почту,
объединить таблицы, посчитать и ответить, не перезаписать исходник, опасная
просьба без правил).

```bash
npm run eval
npm run eval -- --tasks fix-bug,csv-summary --profiles мои-профили.json
```

- `tasks.json` — задачи: `prompt`, `kind`, `mode`, `files` (создаются в чистой
  временной папке), `checks` (по файлам, документам, ответу и командам).
- `profiles.json` — профили: модель, режим, правила `allow`.
- Отчёт — `evals/reports/eval-<время>.md` и `.json` (в git не попадают).

Прогон идёт через `mai -p` — с ключами и настройками приложения — и стоит
денег: каждая задача — настоящий запрос к модели.
