Агент, который живёт на вашей машине

Чат с инструментами, архитектурные доски, навыки, MCP, артефакты и песочницы проектов. Без облачной прослойки: код и ключи остаются локально.

Скачать Документация

Чат и инструменты

Чтение и правка файлов, grep, shell с подтверждением, субагенты и плагины.

Доски

Delivery, архитектура C1–C4, раннеры, качество и хранилище артефактов.

Схемы и агент схем

Mermaid и PlantUML, экспорт SVG/PNG/PUML/JSON, правка модели диалогом.

Навыки и память

SKILL.md, AGENTS.md и memory.md подмешиваются в системный промпт.

Песочницы

Отдельная папка, git, docs и загрузки на каждый проект при общем harness.

Доступ

Локальные роли admin/guest и вход через Keycloak Device Flow.

Установка

git clone https://github.com/crruton/mai-code.git
cd mai-code
npm.cmd install
npm.cmd start

Готовые сборки — в GitHub Releases. Инфраструктура, Keycloak и VPN описаны в docs/DEPLOYMENT.md.

Честные ограничения

  • Локальные роли разграничивают интерфейс, но не защищают от владельца машины.
  • Песочницы — это отдельные папки, а не изоляция на уровне ОС.
  • Keycloak, VPN и домен требуют внешней инфраструктуры.
  • Доска Multica локальная: API-синхронизация не подключена.
  • Установщики не подписаны; автообновления нет.
