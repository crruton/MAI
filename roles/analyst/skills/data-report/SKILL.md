# Отчёт по данным

1. **Пойми вопрос.** Кто читатель и какое решение он примет по отчёту. Если неясно — спроси (ask_user).
2. **Проверь данные:** откуда, за какой период, пропуски, дубликаты, единицы измерения. Опиши ограничения.
3. **Посчитай** формулами в xlsx (create_document со sheets), чтобы расчёт можно было проверить. Не округляй до вывода.
4. **Выводы — сначала главное:** 3–5 тезисов с числами, затем детали и таблицы.
5. **Оформи** docx или pdf, посмотри его preview_document и исправь вёрстку. Исходные данные не меняй — результат рядом новым файлом.
