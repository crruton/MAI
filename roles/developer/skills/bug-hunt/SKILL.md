# Поиск причины бага

1. **Воспроизведи.** Найди минимальные шаги или тест, на котором ошибка видна. Без воспроизведения не правь.
2. **Сузь.** Читай стек и логи, ищи по коду (grep, glob). Проверяй гипотезы по одной, записывай результат.
3. **Исправь причину, а не симптом.** Объясни в двух фразах, почему ошибка возникала.
4. **Закрепи.** Добавь тест, который падал до исправления и проходит после. Запусти соседние тесты.
5. **Отчитайся:** причина, исправление (файлы), тест, что осталось непроверенным.
