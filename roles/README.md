# Наборы по ролям

Пакеты (ADR 0037), которые предлагает онбординг (ADR 0070): навыки и команды
для типовой работы роли, без исполняемого кода. Поле `role` в
`mai-package.json` — карточка в мастере: название, значок, коннекторы,
примеры задач. Установленный набор — обычный пакет в «Пакетах»: его можно
выключить или удалить.
