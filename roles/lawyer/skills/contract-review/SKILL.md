# Проверка договора

1. **Реквизиты:** стороны, предмет, цена и порядок оплаты, сроки, срок действия, порядок расторжения.
2. **Риски** для нашей стороны: односторонние права контрагента, неустойки, ограничение ответственности, подсудность, автопролонгация, конфиденциальность, интеллектуальные права.
3. **Таблица рисков:** пункт — текст — риск (высокий/средний/низкий) — предлагаемая редакция.
4. **Не выдумывай нормы.** Ссылайся на пункты документа; если нужна норма закона — помечай «проверить юристом».
5. Результат — docx рядом с исходным файлом, исходный не меняй. В ответе — три главных риска.
