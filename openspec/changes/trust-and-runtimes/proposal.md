# Proposal: доверие к папке, матрица прав IPC, режим для CLI, изображения, токены

## Проблема

- Открытие папки исполняло её плагины и MCP-серверы и загружало её инструкции.
- Большая часть IPC-каналов не проверяла роль.
- Внешние CLI не соблюдали режим разрешений; запрос разбирался `cmd.exe`.
- Изображения из вложений не доходили до модели.
- Чат и самокоррекция одновременно правили одну папку.
- Токены не учитывались.

## Решение

ADR 0028 (доверие, матрица IPC, блокировка проекта) и ADR 0029 (режим и запуск
CLI). Изображения — `electron/lib/vision.js`, токены — `electron/lib/usage.js`.

## Критерии приёмки

- Плагин недоверенной папки не исполняется; `AGENTS.md` не попадает в промпт.
- Окно доверия появляется при выборе папки; при плагинах и MCP рекомендовано «Ограниченно».
- Тест падает, если канал IPC не внесён в матрицу.
- CLI без флагов для режима не запускается; многострочный запрос доходит без искажений.
- Картинка уходит модели с поддержкой изображений частью `image_url`.
- Второй пишущий прогон в той же папке получает отказ.

## Вне scope

- Плагины в `utilityProcess` (A2.4), `sandbox: true` у окон (A2.5).
- Worktree для параллельных рантаймов (A4.3).
- Индикатор контекста и стоимости (CC5).
