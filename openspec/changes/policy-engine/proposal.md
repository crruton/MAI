# Proposal: PolicyEngine — единая проверка вызовов инструментов

## Проблема

Режим разрешений ограничивал только четыре встроенных инструмента. MCP и
плагины выполнялись без проверки, в том числе в режиме «План». Ответ
пользователя был только «да/нет», журнала решений не было.

## Решение

- Модуль `electron/lib/policy.js`: классы действий, правила allow/ask/deny,
  риск и рекомендация, подсказка правила.
- Модуль `electron/lib/tool-runner.js`: проверка перед каждым вызовом в цикле агента.
- Режимы `manual`, `acceptEdits`, `plan`, `dontAsk`, `bypass`; старый `auto` → `bypass`.
- Ответ «да / да и не спрашивать / нет с пояснением», правила в чате или глобально.
- Журнал `audit.jsonl`.
- Исправления истории: роль `runtime`, сохранение после каждого шага, обрезка по ходам.

## Критерии приёмки

- В режиме «План» ни один источник (встроенный, MCP, плагин) не меняет файл.
- В режиме «Вручную» MCP и плагин без `kind` спрашивают разрешение.
- Правило `deny` сильнее режима «Без вопросов».
- Гостю режим «Без вопросов» недоступен: main понижает его до «Вручную».
- Рекомендованный ответ подсвечен и получает фокус.
- Смешанная сессия (рантайм + агент) не даёт 400.

## Вне scope

- Правила проекта и доверие к папке (A2.3).
- Новый «Авто» с классификатором (CC2.2).
