# MAI Code — контекст OpenSpec

## Что это

Десктопный агент для программирования на Electron. Работает локально, хранит
настройки в `%APPDATA%\mai-code`, вызывает OpenAI-совместимые провайдеры.

## Принципы

1. Локальная работа по умолчанию; сеть — только к выбранному провайдеру и
   явно настроенным сервисам.
2. Опасные действия подтверждает пользователь.
3. Интеграции деградируют, а не блокируют приложение.
4. Документация и решения версионируются вместе с кодом.
5. Непроверенное честно помечается.

## Границы

- В репозитории нет серверной части приложения.
- Keycloak, Multica, Kubernetes, DNS — отдельные сервисы и инфраструктура.
- Песочница-папка не является границей безопасности; Docker-песочница — да.

## Процесс изменения

1. Создать `openspec/changes/<name>/`.
2. Заполнить `proposal.md`, `specs/`, `design.md`, `tasks.md`.
3. Синхронизировать задачи в Multica.
4. Реализовать, обновить `CHANGELOG.md` и ADR.
5. Запустить `npm.cmd run docs:check` и тесты.
