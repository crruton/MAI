# Sandbox isolation

Каждый внешний проект живёт в своей песочнице: отдельная папка, свой `.mai-code`,
свои загрузки и секреты. Общими остаются только глобальные навыки, `AGENTS.md`
и профили моделей.

## Правила

1. Работай только внутри `projectDir`. Не читай и не меняй соседние песочницы.
2. Не пиши в `%APPDATA%\mai-code` напрямую: глобальные настройки меняет только человек
   через интерфейс.
3. Секреты проекта — только в `.env` песочницы; не копируй их в артефакты, логи и диаграммы.
4. Загрузки пользователя — в `<проект>/.mai-code/uploads`; не выноси их за пределы проекта.
5. Перед запуском команды проверь, что она не обращается к чужим путям и общим портам.
6. Если для задачи нужен общий ресурс (БД, ветка, staging) — используй навык
   `resource-locks` и зафиксируй блокировку.
7. Если инструмент требует доступ вне проекта — остановись и спроси подтверждение.

## Проверка перед завершением

- Все изменённые файлы лежат внутри `projectDir`.
- В логах и артефактах нет ключей и токенов.
- Новые зависимости не тянут глобальные конфиги.
- Результат воспроизводится в чистой песочнице без ручных шагов.
