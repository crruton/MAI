# Память проекта MAI Code

## Уроки

- 2026-11-04: упакованное приложение при самоперезапуске теряло первый
  CLI-аргумент. Причина — разная нарезка `process.argv` в dev и packaged.
  Решение: `process.defaultApp` и `MAI_CODE_RELAUNCHED`.
- 2026-11-04: `nativeImage.createFromDataURL` не декодирует SVG. PNG собирается
  только через скрытое offscreen-окно.
- 2026-11-04: в PowerShell команда `npm` может блокироваться политикой
  выполнения. Использовать `npm.cmd`.
- 2026-11-04: Node внутри Electron не доверяет корпоративным сертификатам
  Windows. Нужен `NODE_OPTIONS=--use-system-ca` до старта Node.
- 2026-11-04: MCP-сервер `repowise serve --no-ui` иногда не отвечает на
  initialize. Подключение ограничено таймаутом 30 с, приложение продолжает
  работу без MCP.
- 2026-11-04: `spawn` с командой `npx` на Windows требует `npx.cmd` или shell.
- 2026-11-04: Keycloak Device Flow требует PKCE S256; без `code_challenge`
  Keycloak возвращает ошибку.
- 2026-11-05: `tar -czf` на Windows 10 с 25 тыс. файлов и Defender может идти
  25+ минут. Быстрее: `7za a -ttar`, затем `7za a -tgzip -mx=1`.
- 2026-11-05: упакованное приложение при первом старте выходит с кодом 0 и
  перезапускается с `--use-system-ca`. Проверять нужно новый процесс, а не
  исходный PID.
- 2026-11-05: Docker-песочница проверена на Docker 29.9.2: запуск, порт
  `127.0.0.1:18080→80`, список, логи и остановка.

## Решения

- Песочница-папка не является границей безопасности. Для изоляции процессов и
  сети используется Docker-песочница.
- OpenSpec — вход, Multica — доска. Синхронизация через CLI и маркер в описании.
- Документация читается из `app.getAppPath()/docs`, поэтому попадает в asar.
- Ревизор выключен по умолчанию: это дополнительный расход токенов.

## Ограничения

- Keycloak, Kubernetes, DNS и Multica проверены локально только частично.
- Установщик не подписан, автообновления нет.
- OpenScion не встроен: только внешний сервер и инструкция.
