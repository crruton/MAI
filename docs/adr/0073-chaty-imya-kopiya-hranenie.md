# 0073. Чаты: имя, копия, хранение и точки отката

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CC6.2, CC6.5, CC6.8, CC6.9; продолжение ADR 0044 (сессии по файлам), CC6.1 (чекпоинты)

## Контекст

Чат назывался первыми 60 символами запроса, переименовать его было нельзя;
попробовать другой подход, не потеряв текущий, — тоже. Чаты копились без
срока, перенести чат на другую машину было нечем. Точки отката были только
кнопкой ↺ у каждого сообщения — в длинном чате их не найти.

## Решение

**Имя (CC6.8).** `renameSession(id, title, { auto })` в `session-store.js`.
Ручное имя помечается `titleManual`: автозаголовок его не меняет, а
`saveSession` не затирает его копией сессии, которую main держит во время
прогона. Автозаголовок: после первого ответа main зовёт
`suggestTitle({ provider, model, request, answer })` (agent.js, тот же
`completeOnce`, что у компакции) — 2–6 слов, `cleanTitle` (titles.js) убирает
кавычки, точку, «Заголовок:». Отказ модели — тихо, имя остаётся прежним.
Настройка `autoTitle` (по умолчанию включена). В UI — ✎ в списке чатов и
`/rename [имя]`.

**Копия (CC6.5).** `forkSession(id, { upTo })` — новый чат с той же историей
(или до сообщения), видом, режимом и папками; отметка `forkedFrom`. Не
копируются разрешения «на сессию», состояние прогона и чекпоинты — откат
файлов в копии доступен только для новых правок. ⑂ в списке и `/fork`.

**Хранение (CC6.9).**
- `sessionRetentionDays` (0 — бессрочно): при запуске чаты, не менявшиеся
  дольше срока, удаляются вместе с вложениями и чекпоинтами; идущий — нет.
- Экспорт — «Скачать чат» → «Файл чата MAI» (`*.mai-chat.json`, формат
  `mai-chat` v1, без правил разрешений и состояния прогона). Импорт —
  `/import`: всегда новый id, только известные поля и роли сообщений,
  предел 50 МБ.

**Точки отката (CC6.2).** Двойной Esc (два нажатия за 500 мс, когда агент не
работает и нет правки сообщения) или `/rewind` — список ваших сообщений,
новые сверху, ✎ — где были правки файлов; выбор ведёт в обычное окно отката
CC6.1.

IPC: `sessions:rename`, `sessions:fork`, `sessions:exportFile`,
`sessions:importFile` — любая роль: это свои чаты пользователя.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Копировать чекпоинты в форк | Откат файлов и в копии | Две ветки откатывают одни и те же файлы друг другу | Опасно; копия — для диалога |
| Автозаголовок на каждом ходе | Имя «следит» за темой | Лишние запросы, имя прыгает | Один раз после первого ответа |
| Экспорт в Markdown для переноса | Уже есть | Не восстанавливает историю инструментов | Отдельный формат файла чата |
