# 0057. Повторы и запасная модель

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CC13.2, CC13.3

## Контекст

При 429/503 или обрыве соединения SDK молча повторял запрос один раз, затем
прогон падал с ошибкой. Пользователь не видел, что происходит, а длинная
задача обрывалась из-за минутной перегрузки шлюза.

## Решение

`electron/lib/retry.js`, цикл в `runAgent`:

- Шаг агента повторяет сам цикл (у клиента SDK `maxRetries: 0`): временные
  сбои — 408, 409, 425, 429, 5xx (включая 520–529), обрывы соединения и DNS —
  до 3 повторов с паузой 2, 5, 12 с или по `Retry-After` (до 30 с). Каждый
  повтор — уведомление «503: … — повтор через 5 с (2 из 3)». «Стоп»
  прерывает паузу.
- Повторяем, только если модель ещё ничего не показала в этом шаге — иначе
  текст в ленте задвоился бы; тогда ошибка как раньше.
- **Запасная модель** — `settings.fallbackModel` («провайдер/модель»,
  «Настройки» → «Запасная модель»). Если повторы исчерпаны или основная
  ответила 401/402/403/404, «модель не найдена», «нет средств», «контекст
  переполнен», — дальше прогон идёт на запасной (один раз за прогон, повторы
  заново), с уведомлением и событием `model:fallback`. Субагенты, запущенные
  после переключения, работают на запасной.
- Разовые вызовы (компакция, ревизор) — повторы SDK (`maxRetries: 2`).
- Ошибка запроса (400 и подобные) — без повторов и без запасной.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Повторы SDK (`maxRetries: 3`) | Ничего писать | Невидимо, без Retry-After в паузе «Стоп» не работает, нет запасной | Свой цикл |
| Список запасных моделей | Надёжнее | Сложнее объяснить, какая отвечает | Одна; список — позже |
| Повтор после частичного ответа | Меньше ошибок | Задвоенный текст в ленте | Только «чистый» шаг |

## Последствия

- Запасная модель может отличаться по возможностям (зрение, контекст) —
  после переключения это учитывается заново.
- Проверки: `scripts/test-retry.mjs` (10), раздел [23] `test-agent-loop`
  (два сбоя и ответ, переход на запасную после трёх повторов, 400 без
  повторов).
