# 0045. Рабочие папки чата

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CW1.2 (P0 для Cowork), A1.4

## Контекст

У чата была одна папка — папка проекта. Работа с документами (Cowork) почти
всегда касается нескольких мест: «Документы», папка отдела, выгрузка. Выбор
был плохой: сменить проект (теряются инструкции и память проекта) или включить
«Разрешить файлы вне проекта» — тогда агенту доступен весь диск.

## Решение

`electron/lib/workroots.js`. Корни чата: папка проекта (основная) и
дополнительные папки, которые пользователь добавил к этому чату.

- Добавить — кнопка «＋ папка» в левой панели, над кнопкой проекта (N9):
  путь выбирается только в
  системном диалоге (из окна путь не принимается), весь диск и домашняя папка
  целиком — отказ. Добавляет admin; убрать (×) может любой. Хранится в
  `session.extraDirs`, добавление пишется в журнал.
- Агент обращается к папке как `@имя/путь` (имя — имя папки, повтор — `имя-2`);
  системный промпт перечисляет папки. Абсолютный путь внутри добавленной папки
  тоже принимается.
- Файловые инструменты, рабочая папка `run_shell` и `delete_file` работают
  только внутри корней; выход через `..` из `@папки` — отказ. Флаг «Разрешить
  файлы вне проекта» по-прежнему снимает ограничение.
- Предмет вызова для правил — `@имя/путь`: `write_file(@Документы/**)`.
  Правила на проект (`src/**`) добавленные папки не покрывают. Классификатор
  «Авто» считает добавленные папки «внутри».
- В Docker-песочнице (ADR 0040) добавленные папки монтируются в `/mnt/<имя>`.
- Чекпоинты (ADR 0033) хранят абсолютные пути — откат работает и для них.
- Инструкции, память, навыки и плагины берутся только из папки проекта:
  добавленная папка — данные, не конфигурация.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Несколько проектов в одном чате | Симметрично | Чьи AGENTS.md и память? Неясно, какой «главный» | Один проект + папки-данные |
| Только абсолютные пути | Без нового синтаксиса | Правила привязаны к машине; модель путается в длинных путях | `@имя/путь`, абсолютные тоже принимаются |
| Папки на уровне настроек | Один раз настроил | Доступ шире, чем нужно задаче | Доступ — на чат |

## Последствия

- Доверие к папке (ADR 0028) к добавленным папкам не применяется: из них не
  загружается ничего исполняемого.
- Проверки: `scripts/test-workroots.mjs` (30: имена, `@`-пути, выход, правила,
  «Авто», инструменты, `run_shell`, удаление, Docker), раздел [31] `test-ui`.
