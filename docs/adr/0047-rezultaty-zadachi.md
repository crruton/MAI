# 0047. Результаты задачи

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CW2.6

## Контекст

После задачи с документами пользователь искал созданные файлы по ленте: пути
были разбросаны по карточкам инструментов. Для Cowork результат задачи — это
файлы, и их нужно видеть списком.

## Решение

- Источник — чекпоинты (ADR 0033): каждая запись, правка и удаление
  встроенными инструментами уже записывает файл и было ли его до этого.
  `touchedFiles` (checkpoints.js) и `sessionResults` (`electron/lib/results.js`):
  файл, первый ход, статус сейчас — создан / изменён / удалён, размер.
- Кнопка «📄 Результаты · N» у поля ввода (видна, когда есть файлы;
  обновляется по окончании прогона). Окно: список, превью начала текстового
  файла (до 4000 символов), «Открыть», «В папке».
- «Открыть» программой по умолчанию — только документы и картинки (md, txt,
  csv, json, docx, xlsx, pptx, pdf, png, jpg и т. п.): файл, созданный агентом,
  не должен запускаться (`.bat`, `.exe`, `.js`, `.html`). Остальное — «В папке».
- Окно не может открыть произвольный путь: main принимает только файл из
  результатов этого чата.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Свой журнал созданных файлов | Независим от чекпоинтов | Второй источник правды о тех же записях | Чекпоинты уже есть и точны |
| Постоянная правая панель | Видно всегда | Отнимает место в «Коде», где она редко нужна | Кнопка с числом и окно |
| Открывать любые файлы | Удобно | Запуск того, что создал агент, — исполнение кода | Белый список расширений |

## Последствия

- Файлы, созданные командой `run_shell`, в список не попадают — их не видят и
  чекпоинты.
- Проверки: `scripts/test-results.mjs` (13), раздел [33] `test-ui`.
