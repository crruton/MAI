# 0092. Голосовой ввод: состояние на кнопке, повтор и выбор движка

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог F18; [MAS](../MAS.md)

## Контекст

Ошибки голосового ввода показывались только всплывающим сообщением: оно исчезало,
а кнопка микрофона выглядела как обычно. Неудачное распознавание теряло запись —
надиктовывать приходилось заново. Распознавание было только через MAS: без него
голос не работал вовсе.

## Решение

- Состояние на кнопке: запись, «Распознаю (движок)…», **ошибка** — красная
  кнопка, причина в подсказке («MAS не запущен…», «нет доступа к микрофону»,
  «речь не разобрана», «слишком короткая запись»). Состояние держится до
  следующего нажатия.
- Повтор: если распознавание упало или вернуло пустой текст, запись остаётся в
  памяти окна, рядом с кнопкой — «↻» («распознать ту же запись ещё раз»). Новая
  запись или успех «↻» убирают.
- Движок (`voice.engine`): `mas` (по умолчанию, локально) или `provider` —
  OpenAI-совместимый `/audio/transcriptions` провайдера из настроек; модель —
  «провайдер/модель» (`openai/whisper-1`), язык (`ru`). `voice.js` —
  `voiceConfig`, `providerVoiceStatus`, `providerTranscribe`.
- IPC `voice:status` и `voice:transcribe` выбирают движок; `mas:*` остаются для
  проверки связи с MAS в настройках.
- «Настройки» → «Голос — распознавание речи»: движок, модель провайдера, язык;
  ниже — настройки MAS.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Web Speech API Chromium | Без настроек | В Electron требует ключ Google, звук уходит в Google | Нет контроля |
| Автоповтор при ошибке | Меньше кликов | Повтор того же отказа (MAS не запущен) | Повтор по кнопке |
| Хранить запись на диске | Переживёт перезапуск | Звук на диске — лишний след | Только память окна |

## Последствия

- С движком «провайдер» запись уходит провайдеру — это видно в настройках.
- Проверки: `test-voice` — настройки, готовность провайдера, запрос (модель, язык,
  WAV); `test-ui` [54] — ошибка на кнопке, запись с синтетического микрофона,
  «↻» с той же записью; раздел настроек «Голос».
