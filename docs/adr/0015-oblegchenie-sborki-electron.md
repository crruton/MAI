# 0015. Облегчение сборки Electron

- **Статус:** accepted
- **Дата:** 2026-11-07
- **Контекст:** диагностика производительности, отчёт от 2026-11-07

## Контекст

Сборка `dist/win-unpacked/resources/app.asar` занимала 192 МБ и содержала
13 037 файлов. В пакет попадал весь `node_modules`, включая карты исходников,
TypeScript-декларации, тесты и документацию пакетов.

Замеры до изменений:

| Метрика | Значение |
|---|---|
| `app.asar` | 192 МБ |
| Файлов в пакете | 13 037 |
| `node_modules/mermaid` | 118 МБ, из них 80 МБ — `.map` |
| `mermaid.min.js` | 5.3 МБ, грузился синхронно при открытии доски |

Причина проблемы: `electron-builder.yml` перечислял только включаемые пути и
не исключал служебные файлы зависимостей. `board.html` подключал mermaid
тегом `<script>` до загрузки модуля доски, поэтому 5.3 МБ разбирались при
каждом открытии окна, даже если диаграмма не показывалась.

## Решение

1. В `electron-builder.yml` добавлены исключения: `*.map`, `*.ts`, `*.md`,
   каталоги `test/tests/__tests__/example/examples/doc/docs`, `.github`,
   конфиги линтеров и `tsconfig`.
2. `renderer/board.html` больше не подключает mermaid. Загрузка перенесена в
   `ensureMermaid()` в `renderer/board.js` и выполняется при первом вызове
   `renderMermaidInto()`.
3. В `webPreferences` обоих окон заданы `spellcheck: false` и
   `backgroundThrottling: true`.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Оставить как есть | Нет работы | 192 МБ, медленный старт, Defender сканирует 13 тыс. файлов | Проблема остаётся |
| Перенести `mermaid` в `devDependencies` | Пакет уменьшается ещё на 113 МБ | Нужен шаг копирования `mermaid.min.js` в `renderer/vendor/`, меняется `pack:offline` | Отложено: требует отдельной проверки офлайн-сборки |
| Один `BrowserWindow` вместо окна на раздел | Экономия 300–450 МБ RAM при 3 досках | Переписывание навигации доски | Отложено: крупная правка, нужен отдельный ADR |
| Ленивая загрузка mermaid (выбран) | Минус 5.3 МБ синхронного разбора, простой откат | Диаграмма появляется с задержкой первого рендера | — |

## Последствия

- Пакет уменьшается примерно на 80 МБ карт и несколько тысяч служебных файлов.
- Доска открывается без разбора mermaid; движок грузится при первом показе
  диаграммы.
- Словари проверки орфографии не загружаются.
- Проверить: `npm.cmd run dist`, затем открыть доску «Архитектура» и убедиться,
  что диаграмма рисуется. Проверить офлайн-сборку `npm.cmd run pack:offline`.
- Риск: если `node_modules/mermaid/dist/mermaid.min.js` отсутствует в
  упакованном приложении, диаграмма покажет исходник вместо SVG. Обработка
  ошибки уже есть в `renderMermaidInto()`.
- Не проверено: фактический размер `app.asar` после сборки. Требуется прогон
  `npm.cmd run dist`.
