# 0010. Песочница-папка остаётся режимом по умолчанию

- **Статус:** accepted
- **Дата:** 2026-11-04

## Контекст

Пользователь заметил, что «песочница» — это отдельная папка, а не изоляция
на уровне ОС. Нужна полноценная изоляция с возможностью открывать порты.

## Решение

Два режима с явными названиями:

- **Папка проекта** (по умолчанию) — отдельная директория, свой `.mai-code`,
  git, память. Не является границей безопасности.
- **Docker-песочница** — контейнер с монтированием папки, лимитами, сетью и
  публикацией портов. Является границей для процессов и сети, но не для файлов,
  которые смонтированы.

Пользователь выбирает режим при создании проекта или запускает контейнер из
панели «Песочницы». UI не называет папку «изоляцией».

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Только папка | Просто | Нет изоляции |
| Только Docker | Безопаснее | Требует Docker |
| Два режима | Выбор пользователя | Два пути в коде |

## Последствия

- README и UI честно описывают разницу.
- Docker-режим требует Docker Desktop/Engine.
- Монтирование папки означает, что агент может изменить файлы проекта; для
  полной изоляции нужно копировать проект в контейнер, а не монтировать.
- Порт публикуется на `127.0.0.1` по умолчанию.
