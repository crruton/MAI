# 0100. Локальные модели в один клик

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог N4, источник — [colibri](https://github.com/JustVugg/colibri); текстовый протокол вызовов (CC13.4, ADR 0078); решение гриллинга «без автомаршрута»

## Контекст

Локальный сервер моделей (Ollama, LM Studio, colibri, llama.cpp, Jan) — это
OpenAI-совместимый `/v1`, и подключить его можно было всегда, но вручную: знать
порт, вписать Base URL, придумать ключ (SDK требует непустой), перечислить
модели. Для «строго локально» (ADR 0098) это главный шаг.

## Решение

- `local-models.js` (без Electron): `LOCAL_SERVERS` — Ollama 11434, LM Studio
  1234, colibri/vLLM 8000 (в примерах README colibri — `127.0.0.1:8000/v1`),
  llama.cpp 8080, Jan 1337; `detectLocalModels` — параллельно
  `GET http://127.0.0.1:<порт>/v1/models` с таймаутом 1,5 с; чатовые модели
  первыми, эмбеддинги — в конце; уже добавленный сервер помечен.
- `providerFromLocal` — провайдер `ollama` (или `ollama-2`, если id занят другим
  адресом), имя «Ollama (локально)», ключ `local`, модели из ответа.
- Окно «Провайдеры» → «Локальные модели»: поиск при открытии и по «Найти»,
  «Добавить» в один клик (admin). Если активной модели не было — первая
  найденная становится активной; иначе выбор за пользователем.
- Подсказка: модель без вызова инструментов работает через текстовый протокол
  (CC13.4) — медленнее и с ошибками чаще. Маршрутизации «локально/облако» нет:
  локальная модель — обычный провайдер, можно и запасной моделью.
- IPC `localModels:detect` (ANY), `localModels:add` (ADMIN, сервер проверяется
  заново перед записью).

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Сканировать порты шире | Найдёт нестандартные | Медленно, похоже на сканер | Стандартные порты + ручной провайдер |
| Нативный API Ollama `/api/tags` | Больше сведений (размер, квантование) | Только Ollama | Один путь `/v1/models` для всех |
| Автомаршрут «локально, если доступно» | Меньше кликов | Решение гриллинга — без автомаршрута | Обычный провайдер |

## Последствия

- Порт 8000 занимают и colibri, и vLLM: сервер называется «colibri или vLLM».
- Проверки: `test-local-models` — порты, разбор, настоящие HTTP-серверы (модели,
  пустой, 500, закрытый порт), порядок моделей, «уже добавлен», провайдер и
  свободный id; `test-ui` [58] — блок в окне «Провайдеры» и «Добавить».
