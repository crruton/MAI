# 0049. Документы: создание и чтение DOCX и XLSX

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CW2.1, CW2.2; продолжение ADR 0025 (экспорт)

## Контекст

DOCX и XLSX умел только экспорт ответа кнопкой (ADR 0025): агент не мог сам
создать документ или прочитать присланный. Для задач Cowork («сведи эти
таблицы», «сделай отчёт в Word») это основной результат.

## Решение

Без внешних библиотек, на том же писателе ZIP:

- `create_document({ path, title?, markdown?, sheets? })` — класс `write`
  (как правка файла: режимы, правила, чекпоинт, diff текста в запросе):
  - `.docx` — из Markdown: заголовки, абзацы, списки, таблицы;
  - `.xlsx` — из листов `[{ name, rows, widths? }]`: числа — числами, строки с
    `=` — формулами, логические значения; первая строка жирная и закреплена;
    ширина колонок по содержимому; книга пересчитывает формулы при открытии
    (`fullCalcOnLoad`); «007» остаётся текстом;
  - `.csv` (с BOM и `;` — открывается в Excel), `.md`, `.txt`.
- `read_document({ path, max_rows? })` — класс `read`: DOCX → Markdown
  (стили Heading/Заголовок, списки, таблицы), XLSX → листы по строкам
  (общие строки, inline, числа, логические, формулы как `=…`).
- Читатель ZIP (`export/unzip.js`): центральный каталог, stored и deflate;
  до 2000 записей и 200 МБ распакованного — защита от «zip-бомб».
- Правка документа = `read_document` → изменить → `create_document`. Системный
  промпт «Задачи» (ADR 0046) советует сохранять под новым именем.
- Правило «не спрашивать» для документов — `create_document(папка/**)`.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Библиотеки docx / exceljs | Стили, графики, правка на месте | +несколько МБ в офлайн-дистрибутиве, зависимости в цепочке поставки | Своё на 400 строк покрывает типичные задачи |
| Правка DOCX на месте (замена в XML) | Сохраняет оформление | Текст в Word разбит на произвольные куски `<w:r>`; надёжно — только с полноценной моделью документа | Пересоздание документа; правка с сохранением стилей — следующий шаг |
| Агент пишет XML сам через write_file | Ноль кода | Модель ломает формат | Инструмент с проверенным писателем |

## Последствия

- Оформление исходного DOCX при «правке» не сохраняется: результат — новый
  документ со стилями приложения. Комментарии, режим правок, графики XLSX — не
  поддержаны (остаток CW2.1/CW2.2).
- Проверки: `scripts/test-documents.mjs` (29: ZIP, типы ячеек, формулы,
  закрепление, DOCX туда-обратно, чужой DOCX, инструменты, CSV, отказы; при
  наличии LibreOffice — открытие обоих форматов и вычисление формул).
