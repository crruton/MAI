# 0081. Уведомления на рабочем столе и в мессенджер

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог CW5.4; продолжение ADR 0050 (плановые задачи), 0075 (фоновые субагенты)

## Контекст

Агент работает долго, а пользователь переключается на другие окна. Уведомления
были только у плановых задач и фоновых субагентов, каждое своим кодом; о том,
что агент закончил, ждёт подтверждения или упал, пользователь узнавал, только
вернувшись в окно. Cowork присылает уведомления на рабочий стол, а в планах —
в мессенджер.

## Решение

`electron/lib/notify.js` — один вход для всех событий:
`createNotifier({ Notification, getSettings, isFocused, onClick, fetch })` →
`notify(kind, { title, body, sessionId })`. Виды: `done` (агент закончил),
`approval` (нужно подтверждение), `question` (агент спрашивает), `error`,
`background` (фоновый субагент), `scheduled` (плановая задача).

- **Рабочий стол** — только когда ни одно окно приложения не в фокусе. Клик
  поднимает окно и открывает чат.
- **Каналы мессенджеров** — `settings.notifications.channels`, у каждого свои
  события (по умолчанию: готово, ошибка, плановая задача), выключатель и
  «Проверить» (IPC `notify:test(channelId)`):
  - **Telegram** — бот: `POST https://api.telegram.org/bot<токен>/sendMessage`
    с `chat_id` (личка, группа, канал);
  - **MAX** — бот мессенджера MAX: `POST <api>/messages?chat_id=…` (или
    `user_id=…`), токен в заголовке `Authorization` без `Bearer`, тело
    `{ text }`; адрес API по умолчанию `https://platform-api2.max.ru` (по схеме
    `max-messenger/api-schema`), можно задать свой;
  - **WhatsApp** — WhatsApp Cloud API: `POST
    https://graph.facebook.com/v21.0/<phone_number_id>/messages`, `Bearer`;
    текст (`type: text`) доходит только в 24-часовом окне после сообщения
    пользователя, поэтому можно указать одобренный шаблон (`type: template`,
    имя и язык) — тогда уходит он;
  - **Rocket.Chat** — входящий webhook: `{ text, alias: 'MAI Code' }`;
  - **Webhook** — Slack, Mattermost, Teams (`text`) и Discord (`content`).
  Уходит только вид события, заголовок и первые строки ответа или причины, без
  файлов. Токены ботов и адреса webhook хранятся зашифрованными
  (`SECRET_PATHS`), окно видит «***»; добавить, изменить или удалить канал —
  только admin. Telegram и MAX отвечают 200 и при ошибке — смотрится и тело
  (`ok: false`, `success: false`). Ошибка доставки — в журнал, без падения.
  Старая настройка с одним `webhookUrl` читается как канал webhook и
  показывается в окне каналом «legacy».
- Одно и то же (вид, заголовок, чат) не повторяется чаще раза в 10 с.
- Настройки: «Уведомления» — выключатель и виды для рабочего стола, адрес
  webhook и виды для него (по умолчанию: готово, ошибка, плановая задача),
  «Проверить на рабочем столе».
- В main: прогон чата (готово/ошибка), `makeApprover`, `makeAsker`, фоновые
  субагенты и `notifyScheduled` идут через `notify`.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Бот Telegram/Slack с двусторонней связью | Ответить с телефона | Сервер, токены бота, приём команд — это CW5.5 и N8 | Позже |
| Push на телефон через сервис | Без мессенджера | Внешний сервис и аккаунт | Webhook уже есть у мессенджеров |
| Уведомлять всегда, даже в фокусе | Проще | Шум | Только вне фокуса |

## Последствия

- Ответить на подтверждение из мессенджера нельзя — только вернуться в окно
  (двусторонние боты — N8).
- WhatsApp вне 24-часового окна без шаблона молча не доставляет (Meta
  отвечает 200) — для уведомлений лучше задать шаблон.
- Документация MAX (dev.max.ru) из среды разработки недоступна; формат
  запроса взят из официальной OpenAPI-схемы `max-messenger/api-schema`.
- Проверки: `scripts/test-notify.mjs` (настройки, перенос старого webhook,
  неполные и выключенные каналы, запросы Telegram, MAX (chat_id/user_id,
  свой адрес), WhatsApp (текст и шаблон), Rocket.Chat, webhook; фокус и
  рабочий стол, события по каналам, `success: false` у MAX, клик, повтор за
  10 с, проверка одного канала); `test-secrets` — токены каналов шифруются;
  `test-ui` [44] — набор типов, поля MAX, сохранение канала Telegram.
