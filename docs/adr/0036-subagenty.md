# 0036. Субагенты

- **Статус:** accepted
- **Дата:** 2026-11-20
- **Контекст:** бэклог CC8.1–CC8.4, CC8.7

## Контекст

Поиск по большому проекту и разбор логов забивали контекст основного агента:
десятки результатов `read_file` и `grep` оставались в истории, хотя нужен был
один вывод. Ревизор (ADR 0006) работал как отдельная модель, но не умел читать код.

## Решение

Инструмент `agent` (`electron/lib/agent-defs.js`, `runSubagent` в `agent.js`):
`{ type, description, prompt }` → отдельный прогон `runAgent` с одной задачей
пользователя и своей историей; родитель получает только последний ответ
субагента с числом шагов и токенами. Шаги субагента видны живым выводом в
карточке вызова, в историю родителя не попадают.

- Типы: встроенные `explore` (только чтение), `plan` (только чтение, итог —
  план), `general` (все инструменты родителя); свои — `.mai-code/agents/<имя>.md`
  (доверенная папка) и `<данные>/agents/<имя>.md`, frontmatter `description`,
  `tools` (через запятую; без поля — все). Встроенные имена не переопределяются.
- Разрешения не шире родителя (CC8.7): тот же режим, правила, роль, доверие,
  хуки и функция подтверждения — запросы приходят в ту же ленту. Правки
  субагента идут в чекпоинт хода родителя, откат вернёт и их.
- Субагенту недоступны `agent` (без вложенности), `ask_user`, `exit_plan`,
  `todo_write`; ревизор и хук `Stop` к нему не применяются.
- Несколько вызовов `agent` в одном шаге, все типы — только чтение, идут
  параллельно (CC8.4); остальное — по очереди, с сохранением после каждого вызова.
- `agent` — класс `read` в PolicyEngine: сама передача задачи ничего не меняет,
  каждое действие субагента проверяется отдельно.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Параллельно всё | Быстрее | Два запроса разрешения сразу, правки одних файлов | Только чтение — безопасно |
| Субагент в отдельном процессе | Изоляция | Дорого; разрешения и чекпоинты пришлось бы прокидывать по IPC | Тот же процесс, те же проверки |
| Своя модель у типа | Дешёвая модель для поиска | Нужен выбор провайдера в типе | Отдельная задача |

## Последствия

- Лимит шагов субагента — `subagentMaxIterations` (по умолчанию 20).
- Субагент `general` в режиме «Без вопросов» правит файлы без вопросов, как и родитель.
- Проверки: `scripts/test-agent-defs.mjs`, раздел [17] `test-agent-loop`, [24] `test-ui`.
