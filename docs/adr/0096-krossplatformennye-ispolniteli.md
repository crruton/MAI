# 0096. Кроссплатформенные исполнители: выбор оболочки и остановка дерева процессов

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог F26; `run_shell` (ADR 0054/0055), рантаймы (ADR 0029), хуки

## Контекст

Приложение писалось под Windows. Ветки под macOS/Linux были, но разрозненно:
остановка «вместе с потомками» была реализована четыре раза, и в стадиях
деплоя и рантаймах на macOS/Linux останавливался только родительский процесс
(`child.kill`) — `npm run dev` → `node` оставался жить. Оболочку `run_shell`
выбрать было нельзя (`shell: true` — cmd.exe или /bin/sh), а модель не знала,
в какой ОС и оболочке пишет команды. В CI не было macOS.

## Решение

- `proc.js` (без Electron): `shellFor(command, {shell})` — `auto` (Windows —
  cmd.exe `/d /s /c "…"` с UTF-8 консолью; macOS/Linux — `$SHELL`, если это bash
  или zsh, иначе `/bin/sh`), `cmd`, `powershell`, `pwsh` (`-NoProfile
  -NonInteractive`, вывод UTF-8), `bash`, `zsh`, `sh`; `spawnShell` — запуск в
  своей группе процессов на macOS/Linux; `killTree` — Windows `taskkill /T /F`,
  иначе сигнал группе `-pid` (или процессу, если группы нет) и через 3 с SIGKILL.
- `run_shell`, фоновые команды, хуки, стадии деплоя и рантаймы используют
  `killTree`; деплой и рантаймы запускаются в своей группе процессов.
- Настройка `shell` (по умолчанию `auto`; менять — admin): «Настройки» →
  «Команды агента» → «Оболочка run_shell на компьютере». Системный промпт
  называет ОС и оболочку («Система: macOS; оболочка run_shell: zsh»).
- CI: задача `macos` — `npm test`, smoke и интерфейс в Electron.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Всегда bash (Git Bash на Windows) | Один синтаксис | Git Bash есть не у всех, пути MSYS | auto по ОС + выбор |
| `$SHELL` любой (fish, nu) | Как в терминале | Синтаксис не POSIX — модель ошибается | Только bash/zsh, иначе sh |
| tree-kill из npm | Готово | Зависимость; на Linux — ps по дереву | Группы процессов надёжнее |

## Последствия

- Команды агента на macOS/Linux идут в привычной оболочке, «Стоп» и таймаут
  останавливают всё дерево.
- Docker-песочница по-прежнему `sh` внутри контейнера.
- Проверки: `test-proc` — выбор оболочки на трёх ОС, taskkill / сигнал группе /
  запасной путь, настоящая команда с потомком (остановлены все) и `/bin/sh`;
  на Windows — cmd.exe с UTF-8; задача CI `macos`.
