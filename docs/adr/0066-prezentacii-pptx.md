# 0066. Презентации PPTX

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CW2.3; продолжение ADR 0049

## Контекст

Агент создавал DOCX и XLSX (ADR 0049), но не презентации — частый результат
задач Cowork («сделай из отчёта 5 слайдов для совещания»). Читать PPTX он мог
только как вложение (текст подряд, без слайдов).

## Решение

`electron/lib/export/pptx.js` на том же ZIP-писателе, без библиотек:

- `create_document` с `.pptx`: `slides: [{ title, subtitle?, bullets: [строка |
  { text, level }] }]` или Markdown (`#`/`##` — новый слайд, строка сразу после
  заголовка — подзаголовок, «- » — пункт, отступ — уровень до 4). Первый слайд
  без пунктов — титульный. 16:9, тема с одним акцентным цветом, полоса под
  заголовком; спецсимволы экранируются.
- Минимальный набор частей PowerPoint: презентация, мастер, макет, тема,
  слайды со связями.
- `read_document` с `.pptx` — по слайдам: «## Слайд N: заголовок» и пункты.
- В запросе разрешения — текст будущей презентации по слайдам (diff).

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| pptxgenjs | Картинки, таблицы, графики | Зависимость ~1 МБ; ADR 0049 — без библиотек | Своё на нужное подмножество |
| Заполнение шаблона пользователя | Фирменный стиль | Разбор чужих макетов и плейсхолдеров — отдельная задача | Следующий шаг |

## Последствия

- Картинки, таблицы, графики, заметки докладчика и фирменные шаблоны — не
  поддержаны.
- Проверки: `scripts/test-documents.mjs` [4б] (Markdown → слайды, туда-обратно,
  части пакета, инструменты, отказ) и [5] (LibreOffice открывает pptx и
  конвертирует в PDF); вручную — python-pptx читает файл, вид слайда проверен
  рендером.
