# 0101. impeccable 4.10.0, обновление встроенных навыков и пакет с хуком проверки UI

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог N5, источник — [pbakaus/impeccable](https://github.com/pbakaus/impeccable) (Apache 2.0); пакеты (ADR 0037), хуки (ADR 0035)

## Контекст

Встроенный навык impeccable был версии 4.8.1, вышла 4.10.0 (команда
`foundations`, новые справочники: critique-rubric, foundations, new-work-comp,
new-work-world, motion-reviewer). Установщик встроенных навыков никогда не
перезаписывал установленные — обновление до пользователей не дошло бы. В
копии навыка пути к скриптам были вида `.claude/skills/impeccable/…`, а в MAI
навыки лежат в `%APPDATA%\mai-code\skills`. Наконец, у impeccable есть хук
после правок, но он запускает их бинарный движок — для примера тяжело.

## Решение

- `skills/impeccable` — копия `.claude/skills/impeccable` из тега
  `skill-v4.10.0` (та же, из которой была 4.8.1), с `LICENSE` и `NOTICE.md`.
  Пути `.claude/skills/impeccable/` заменены на `<skill-base-dir>/` (папка с
  SKILL.md, так навык сам описывает её в шаге загрузки контекста).
- `installBundledSkills` обновляет установленный навык, если во встроенном
  `version` новее; прежняя копия (возможно, с правками пользователя) уходит в
  `skills/.previous/<имя>-<версия>`. Навыки без версии не трогаются, как раньше.
- Хуки пакетов: `${MAI_PACKAGE_DIR}` в командах заменяется на папку пакета в
  кавычках — скрипт хука может лежать в пакете.
- Пример `examples/packages/impeccable-check`: хук `PostToolUse` на
  `write_file|edit_file` — после правки UI-файла (`.html`, `.css`, `.jsx`,
  `.tsx`, `.vue`, `.svelte`…) детектор без зависимостей ищет `outline: none`,
  `transition: all`, шрифт < 12px, `z-index` 1000+, `!important` ×3, `<img>` без
  `alt`, клик на `<div>`, поле только с placeholder, запрет масштабирования —
  и возвращает находки агенту (`additionalContext`), ничего не блокируя.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Хук `impeccable hook` из навыка | Полные проверки движка | Скачивает и запускает бинарный движок на каждую правку | Свой лёгкий детектор как пример |
| Перезаписывать встроенные навыки всегда | Просто | Теряются правки пользователя | Только при новой версии, с копией |
| Копия `plugin/` с `${CLAUDE_SKILL_DIR}` | Без жёстких путей | Переменной нет в MAI | `<skill-base-dir>` — как в самом навыке |

## Последствия

- Обновлённый навык у пользователей появится при следующем запуске; правки
  4.8.1 — в `.previous`.
- Проверки: `test-storage-safety` [6] — обновление по версии, `.previous`,
  повторный запуск, настоящий встроенный impeccable 4.10.0 без `.claude/`;
  `test-hook-examples` — `${MAI_PACKAGE_DIR}`, правила CSS и разметки, чистый
  UI, хук через настоящий исполнитель хуков, не UI-файл.
