# 0074. Интерфейс: `!команда`, статусная строка, тема, доступность

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CC7.10, CC7.12, CC7.15, CC7.16, CC7.17

## Контекст

В Claude Code команду можно запустить самому (`!npm test`) — без модели, а
вывод попадает в контекст. Модель, режим, ветка и стоимость были разбросаны
по окну. Тема была только тёмной, хотя `settings.theme` существовал. Окна
(модалки) не были доступны с клавиатуры: фокус оставался под окном, Esc
работал не везде, мелкий текст имел контраст ниже 4.5:1.

## Решение

**`!команда` (CC7.10).** Строка, начинающаяся с `!` (одна строка, не `!!`),
не уходит модели: IPC `shell:direct` (только admin) выполняет её в папке
проекта тем же `execute`, что и `run_shell` (таймаут, обрезка вывода,
кодировка Windows), после проверки guardrails, и пишет в историю сообщение
пользователя с выводом (`direct: true`) — агент увидит его следующим ходом.
Запись в аудит. Без чата чат создаётся. Команда идёт на хосте, даже если для
агента включена Docker-песочница: это действие самого пользователя.

**Статусная строка (CC7.12).** Строка под полем ввода (`#statusline`,
`role="status"`): модель · режим · ⎇ ветка git · контекст % · стоимость чата.
Состав — «Настройки» → «Статусная строка» (`settings.statusLine`; по
умолчанию без контекста — для него есть индикатор с цветом). Ветка — IPC
`git:branch` (`currentBranch` из git-guard), обновляется при запуске, после
прогона и при смене папки. Стоимость — `sessionCost()`, общий с `/cost`.

**Тема (CC7.16).** «Тёмная / Светлая / Как в системе» (`settings.theme`).
main ставит `nativeTheme.themeSource`, и CSS обоих окон (`styles.css`,
`board.css`) следует `prefers-color-scheme` — без JS в окнах. Цвета, что были
зашиты, вынесены в переменные (`--hover`, `--code-*`, `--tint`, `--topbar`).
Фон окна и цвета полосы заголовка меняются по `nativeTheme.on('updated')`.

**Вставка изображений (CC7.15)** уже работала: `Ctrl+V` скриншота → чип
вложения с превью (ADR 0030 вложения). Отмечено как покрытое.

**Доступность (CC7.17).**
- `openModal`: `role="dialog"`, `aria-modal`, `aria-labelledby` на заголовок;
  фокус уходит в окно и возвращается на элемент, откуда открыли; Esc закрывает
  верхнее окно; Tab не выходит за пределы окна.
- `:focus-visible` — видимая рамка с клавиатуры; `prefers-reduced-motion`
  выключает анимации.
- `--text-faint` поднят до 5.2:1 (тёмная) и 5.5:1 (светлая) на фоне панелей.
- Кнопки-значки (⚙, +, ➤, ■, ✎, ⑂, ✕) подписаны `aria-label`.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| `!команда` через агента в «Без вопросов» | Один путь | Нужна модель и токены; режим меняется | Прямой запуск дешевле и предсказуемее |
| Тема классом `data-theme` из JS | Не зависит от ОС | Нужен JS в каждом окне, системная — отдельно | `nativeTheme` + media query покрывают все три |
| Своя статусная строка-скрипт (как в Claude Code) | Гибко | Выполнение кода пользователя в окне | Набор полей галочками |
