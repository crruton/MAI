# 0052. Каталог коннекторов и токены MCP

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CW3.1; продолжение ADR 0041 (OAuth) и ADR 0048 (отправка)

## Контекст

Чтобы подключить сервис, нужно было знать адрес его MCP-сервера, вписать его
в окно MCP и разобраться со входом. Токены для серверов без OAuth лежали в
`settings.json` открытым текстом (`headers`, `env`) и целиком уходили в окно.

## Решение

- `electron/lib/connectors.js`: каталог готовых подключений. Встроенные — только
  официальные удалённые серверы с адресом из документации сервиса:
  Linear (`https://mcp.linear.app/mcp`, OAuth), Notion
  (`https://mcp.notion.com/mcp`, OAuth), GitHub
  (`https://api.githubcopilot.com/mcp/`, персональный токен — вход GitHub
  работает через заранее зарегистрированные приложения, без DCR), Sentry
  (`https://mcp.sentry.dev/mcp`, OAuth). Только HTTPS.
- Организация задаёт свои коннекторы в `managed-settings.json` (ADR 0038):
  `connectors: [{ id, name, url, auth: 'oauth' | 'token' | 'none', tokenHeader?,
  tokenPrefix?, category?, description?, docs? }]`; с тем же `id` — сильнее
  встроенного; `onlyManagedConnectors: true` скрывает встроенные.
- `/connectors` (и кнопка в окне MCP): карточки с категорией, способом входа и
  состоянием. «Подключить» записывает сервер в `mcpServers` (поле `connector`)
  и подключает; для OAuth сразу открывает вход в браузере (ADR 0041), для токена —
  поле ввода и «Где взять токен». Перевод строки в токене отклоняется (подмена
  заголовков). «Отключить» удаляет сервер, вход и токен. Подключение — admin.
- Токены MCP: `mcpServers.*.headers.*` и `mcpServers.*.env.*` шифруются
  хранилищем ОС (ADR 0031); в окно уходят как `***`; при сохранении из окна `***`
  не затирает настоящее значение.
- Отправка через коннекторы спрашивается всегда (ADR 0048).

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Большой встроенный каталог из публичных списков | Больше сервисов | Адреса меняются, многие — неофициальные прокси | Только официальные; остальное — каталогом организации |
| Каталог через маркетплейс пакетов (ADR 0042) | Обновляется без релиза | Пакет — исполняемый код; коннектору нужен только адрес | Данные в managed-settings; пакеты с `mcp.json` тоже работают |
| Токен в переменной окружения | Привычно | Виден всем процессам пользователя | Зашифрованный заголовок |

## Последствия

- Адреса встроенных коннекторов могут устареть — нужна проверка при релизе;
  организация может переопределить адрес без нового релиза.
- Проверки: `scripts/test-connectors.mjs` (15: каталог, организация, отбор,
  записи OAuth/токен, перевод строки, шифрование заголовков и env),
  `test-secrets-electron` [4] (на диске, в окне `***`, сохранение не затирает),
  раздел [37] `test-ui`.
