# 0068. Превью документа для самопроверки агентом

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CW2.5; продолжение ADR 0049, 0066, 0067

## Контекст

Агент создавал документы, но проверял их только текстом (`read_document`):
обрезанные таблицы, пустые слайды, «съехавшая» вёрстка в тексте не видны.
Cowork перед сдачей смотрит на результат глазами. У моделей со зрением
(ADR 0035, CC1.3) уже есть путь «картинка из инструмента → следующее сообщение».

## Решение

- Инструмент `preview_document` (класс read, есть у explore/plan и у ревизора):
  `.docx`, `.pptx`, `.xlsx`, `.csv`, `.md`, `.txt` → HTML (`documentHtml`:
  тот же разбор, что у `read_document`; слайды — карточки 16:9 через
  `slidesToHtml`) → `renderPng` в main; `.pdf` — `pdftoppm`, если установлен.
  1–4 первые страницы (по умолчанию 2), PNG в папку превью (временная папка
  системы, старше суток удаляется).
- `renderPng(BrowserWindow, html)` (`pdf-render.js`): окно вне экрана в той же
  отдельной сессии, что и PDF; CSP `default-src 'none'` запрещает скрипты и
  ресурсы страницы, сетевые и файловые запросы отменяются, переходы и новые
  окна запрещены. JavaScript окна включён только для `executeJavaScript` из
  main — измерить высоту документа; страница режется на куски A4 (794×1123).
- Встроенный инструмент может вернуть `{ content, images }`; `runToolCall`
  передаёт `images` в результат, цикл агента кладёт их в сообщение инструмента,
  а `attachToolImages` показывает модели (как картинки `read_file`).
- Отказы с подсказкой: модель без зрения, вне приложения (нет Chromium), PDF
  без `pdftoppm`, неподдерживаемый формат.
- Промпт «Задачи»: перед сдачей документа посмотреть его `preview_document`,
  исправить найденное и посмотреть снова.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| LibreOffice → PDF → PNG | Точная вёрстка Office | Есть не у всех, медленно | Нельзя рассчитывать; PDF через pdftoppm — где есть |
| Только текстовая самопроверка | Ничего не нужно | Не видит вёрстку | То, что было |
| Превью PDF во встроенном просмотрщике Chromium | Без poppler | Плагин PDF не рисуется вне экрана | Не работает в скрытом окне |

## Последствия

- Превью DOCX/PPTX/XLSX приближённое: шрифты и поля Office не повторяются,
  структура и содержание — те же. Агенту это сказано в результате.
- Картинки превью занимают контекст: не больше 4 страниц за вызов, общие лимиты
  картинок (`IMAGE_LIMITS`) действуют.
- Проверки: `scripts/test-pdf.mjs` [5] — длинный документ режется на страницы,
  слайды-карточки, превью без сети и скриптов, docx/pptx/xlsx дают PNG для
  модели, отказы (без зрения, формат, без Chromium), PDF через pdftoppm или
  понятный отказ.
