# 0116. Атрибуция коммитов агента: трейлеры Agent-Model и Agent-User

- **Статус:** accepted
- **Дата:** 2026-11-26
- **Контекст:** [бэклог командной работы](../BACKLOG-TEAM.md) E2.7, MAI Ship (ADR 0110), PolicyEngine (ADR 0027), вход через Keycloak (ADR 0093)

## Контекст

В команде коммиты делают люди и агенты разными моделями. По истории git не видно, какая
модель написала изменение и кто из людей запустил агента. MAI Ship (ADR 0110) должен знать
модель исполнителя, чтобы approver был из другого семейства. Коммиты в MAI делает сам агент
через `run_shell` (команда `/commit` — промпт), поэтому просить модель дописать трейлеры
ненадёжно.

## Решение

- **Где.** `effectiveCommand` в `tools/shell.js` — та же функция, что даёт итоговую строку
  для подтверждения (ADR 0027). Человек видит в окне подтверждения команду уже с трейлерами.
- **Что.** К простому `git commit …` добавляются `--trailer "Agent-Model: <провайдер>/<модель>"`
  и, если вошёл пользователь Keycloak, `--trailer "Agent-User: <имя> <email>"`. Локальный
  режим без Keycloak — только `Agent-Model`.
- **Когда не трогаем.** Составная команда (`&&`, `|`, `;`), подстановка `$(…)` или обратные
  кавычки, другая подкоманда git, трейлер `Agent-*` уже есть, git старше 2.32 (нет
  `--trailer`), выключено настройкой `attribution.enabled: false`.
- **Значения.** Из имени и email вырезаются символы, которые оболочка разворачивает или режет:
  `" \` $ % ! \` и переводы строк.
- **Кто.** Основной агент и субагенты (ADR 0075) — с моделью своего прогона.
- **Модуль** `electron/lib/attribution.js`, без Electron.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Просить модель в промпте `/commit` | просто | модель забывает и ошибается в формате | атрибуция нужна для гейта Ship |
| Хук `prepare-commit-msg` в репозитории | ловит любые коммиты | правит чужие `.git/hooks`, конфликтует с husky и lefthook | репозиторий пользователя не трогаем |
| `core.hooksPath` через переменные окружения | без правки репозитория | отключает хуки проекта | ломает проверки проекта |
| Только `Co-Authored-By` | понимает GitHub | не различает модели и пользователя | трейлеры читаются `git log --format=%(trailers)` |

## Последствия

- Проще: по `git log` видно модель и человека; MAI Ship читает `Agent-Model` без догадок.
- Сложнее: коммит составной командой (`git add . && git commit …`) остаётся без атрибуции.
  Навык `to-mr` и `/commit` делают коммит отдельной командой.
- Проверено: настоящий коммит через `cmd.exe` с кириллицей в имени; `git log` видит трейлеры.
  Не проверено: bash и PowerShell как оболочка `run_shell` на живой машине (кавычки те же).
