# 0009. OpenScion не заменяет локальный git

- **Статус:** accepted
- **Дата:** 2026-11-04

## Контекст

Вопрос: если поднять локальный git, можно ли применить OpenScion вместо него?

## Решение

Нет. OpenScion — серверная SCM-система для больших монорепозиториев, а не
локальный git-клиент. MAI Code продолжает создавать обычный git-репозиторий.
OpenScion подключается как внешний сервер:

1. развернуть сервер OpenScion;
2. создать репозиторий;
3. импортировать проект командой `opnscn import . <url>`;
4. настроить CI и клиентов.

В песочнице создаётся `docs/OPENSCION.md` с этой инструкцией. Полная
документация — `docs/OPENSCION.md`.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Заменить git | Единая система | Нет локальной работы, GPL-3.0, сервер |
| Оставить git + remote | Работает офлайн | Две системы |
| Не поддерживать | Просто | Нет ответа на запрос |

## Последствия

- Пользователь не теряет привычный git и GitHub/GitLab.
- OpenScion остаётся опцией для монорепозиториев и агентского CI.
- GPL-3.0 несовместима с MIT при встраивании кода, поэтому только внешний сервис.
