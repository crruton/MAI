# 0080. Предел памяти, инструкции других агентов, кэш промпта, дубли навыков

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог CC4.5, CC4.6, CC5.4, CC10.5

## Контекст

Четыре мелких разрыва: память в системном промпте молча обрезалась на 6000/12000
символов; инструкции проектов, написанные для Claude Code, Gemini CLI, Cursor и
Copilot, не читались; кэш промпта Claude не использовался (каждый шаг — полная
цена всего диалога); навыки с одинаковым именем из проекта, пакета и
глобальной папки молча перекрывали друг друга и дважды стояли в промпте.

## Решение

**Предел памяти (CC4.5)** — `memory-limits.js`: `MEMORY_LIMITS` (глобальная
6000, проекта 12000), `memoryForPrompt`: сверх предела — обрезка с пометкой
«[Память обрезана: в промпте N из M символов. Остальное — memory_read]», так
что агент знает, где дочитать. Панель «Память» — индикатор «N из предела» под
каждым полем, сверх предела — предупреждение (`memory:read` отдаёт `limits`).

**Инструкции других агентов (CC4.6)** — `projectInstructions(dir, { compat })`:
кроме `AGENTS.md`/`AGENTS.local.md` — `CLAUDE.md`, `CLAUDE.local.md`,
`GEMINI.md`, `.github/copilot-instructions.md`, `.cursorrules`, правила
`.cursor/rules/*.mdc` с `alwaysApply: true`; правила без него — списком
(файл, описание, маски файлов) для чтения по запросу. Файл, который только
ссылается на AGENTS.md (`@AGENTS.md`), и повторы того же текста пропускаются.
Только в доверенной папке, как AGENTS.md. Выключатель — «Настройки» →
«Инструкции других агентов» (`compatInstructions`).

**Кэш промпта (CC5.4)** — `capabilities.cache` (Claude по имени или флаг
модели `cache`), `withCacheControl(messages)`: метки `cache_control:
ephemeral` на системном промпте и последнем сообщении (до 4 разрешено — берём
2: система и «хвост» диалога). Только в chat.completions; Responses API и
модели OpenAI/DeepSeek/Qwen кэшируют общий префикс сами — для них префикс уже
стабилен (системный промпт и инструменты не меняются между шагами). Шлюз
отверг `cache_control` — повтор без меток до конца прогона с уведомлением.
`normalizeUsage` учитывает `cache_read_input_tokens`; кэш виден в `/cost`.
Выключатель — `settings.promptCache: false`.

**Дубли навыков (CC10.5)** — `skill-conflicts.js`: `uniqueSkills` — один навык
на имя в промпте агента (приоритет: проект → пакеты → глобальные, как и у
`load_skill`); `skillConflicts` — при установке пакета, из каталога и роли
ответ содержит `warnings`: «Навык X уже есть (…) — работать будет навык из
«…»», окно показывает их уведомлением. Панель «Навыки» помечает перекрытые:
«не используется: перекрыт навыком …».

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Поднять предел памяти | Меньше обрезок | Дороже каждый запрос | Пометка + memory_read |
| Читать CLAUDE.md только без AGENTS.md | Нет дублей | Теряются отличия | Дедупликация по тексту |
| Метки кэша на каждом сообщении | Максимум попаданий | Лимит 4 метки у Anthropic | Система + последнее |

## Последствия

- Правила Cursor с масками (`globs`) не применяются автоматически по файлу —
  агент видит их список и читает сам.
- Проверки: `test-instructions` [4] (ссылка и копия пропущены, Copilot,
  `.cursorrules`, alwaysApply, правила по запросу, свой CLAUDE.md, выключатель,
  разбор .mdc), [5] (предел памяти); `test-capabilities` (флаг кэша, метки,
  картинки, usage, дубли навыков); `test-agent-loop` [35] (метки у Claude, нет у
  gpt, отказ шлюза → без меток); `test-ui` [10] (индикатор памяти).
