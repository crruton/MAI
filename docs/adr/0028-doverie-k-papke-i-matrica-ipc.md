# 0028. Доверие к папке проекта и матрица прав IPC

- **Статус:** accepted
- **Дата:** 2026-11-19
- **Контекст:** `openspec/changes/trust-and-runtimes/`, бэклог A1.11, A2.2, A2.3, A3.6, Q2

## Контекст

- При выборе папки приложение сразу импортировало `.mai-code/plugins/*.js` в
  main-процесс с полным доступом к Node, запускало процессы из
  `.mai-code/mcp.json` и подмешивало `AGENTS.md` и `memory.md` в системный
  промпт. Открыть чужой репозиторий значило выполнить его код.
- Проверка роли была в 30 из 141 обработчиков IPC. Без неё работали, например,
  `runtimes:run`, `mcp:connect`, `infra:pushSecrets`, `repowise:install` и
  `repowise:distill` — последний выполнял произвольную команду оболочки.
  `app:openPath` запускал любой файл ассоциированной программой.
- Чат и самокоррекция могли одновременно править одну папку.

## Решение

**Доверие к папке.** Модуль `electron/lib/trust.js`, состояния `trusted`,
`restricted`, `unknown`, файл `trust.json` в папке данных. Решение наследуется
вложенными папками; песочницы, созданные приложением, доверены всегда.

| Что | trusted | restricted / unknown |
|---|---|---|
| Плагины `.mai-code/plugins` | загружаются | нет |
| MCP `.mai-code/mcp.json` | подключаются | нет |
| `AGENTS.md`, `memory.md`, навыки проекта | в промпте | нет, в промпте предупреждение |
| Режим «Без вопросов» | действует | понижается до «Вручную» |
| Стадии досок (`boards.json`) | запускаются | нет |

При `unknown` запуск (чат, рантайм, самокоррекция) возвращает `needTrust`, окно
спрашивает и повторяет запуск; при выборе папки окно спрашивает сразу. В окне
перечислено найденное (`inspectProject`), код при этом не загружается. Если в
папке есть плагины или MCP, рекомендован ответ «Ограниченно». «Доверяю» может
выбрать только admin, «Ограниченно» — любая роль.

**Матрица прав IPC.** Модуль `electron/lib/ipc-permissions.js`: каждый канал —
`any`, `admin` или `self` (роль проверяет обработчик, право зависит от
аргументов). `guardIpc` оборачивает `ipcMain.handle` до регистрации
обработчиков; гость на `admin`-канале получает `{ ok: false, forbidden: true }`.
Канал вне матрицы считается `admin`. По решению D1 локальная роль — режим
интерфейса; реальной границей матрица становится при входе через Keycloak.

Попутно: `app:openPath` открывает только папки; `repowise:distill` — admin и
guardrails.

**Блокировка проекта.** `electron/lib/project-lock.js`: чат, самокоррекция и
рантайм с правом записи занимают папку на время прогона; второй получает отказ
с именем владельца.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Доверять всему, предупреждать в журнале | Без нового диалога | Код уже выполнен к моменту предупреждения | Не защищает |
| Плагины в `utilityProcess` вместо доверия | Изоляция кода | MCP и инструкции остаются; большой объём | Нужен и он (бэклог A2.4), но поверх доверия |
| `requireAdmin` в каждом обработчике | Привычно | Новый канал легко оставить открытым | Матрица + тест надёжнее |

## Последствия

- Существующие пользователи увидят вопрос о доверии один раз для каждой папки.
- Гость больше не запускает внешние рантаймы, не подключает MCP и не трогает
  секреты Vault.
- Правила разрешений проекта (`.mai-code/settings.json`) теперь можно читать
  для доверенных папок — отдельная задача.
- Проверки: `scripts/test-trust.mjs`, `scripts/test-ipc-permissions.mjs`,
  `scripts/test-project-lock.mjs`, раздел [8] `scripts/test-agent-loop.mjs`,
  раздел [15] `scripts/test-ui.mjs`.
