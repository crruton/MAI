# 0065. Проекты

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CW1.5

## Контекст

«Проект» был папкой. Для задач Cowork набор шире: основная папка, несколько
папок с данными (ADR 0045), инструкции «для кого и в каком виде», нужные
коннекторы (ADR 0052) и вид чата (ADR 0046). Всё это приходилось собирать
в каждом новом чате заново.

## Решение

`electron/lib/projects.js`, `<данные>/projects.json`, окно «🗂 Проекты»
(`/projects`):

- Проект: название, основная папка (её `AGENTS.md`, `memory.md`, доверие и
  чаты — как раньше), дополнительные папки, инструкции (до 20 000 символов),
  коннекторы (пусто — все подключённые), вид чатов (Задача / Код).
- Папки выбираются только в системном диалоге (`projects:pickDir`) и
  проверяются: полный путь, папка существует, не весь диск и не домашняя
  целиком. Создание, изменение, удаление и открытие — admin.
- «Открыть»: основная папка становится текущей (`settings.activeProject`), новый
  чат — с видом проекта. В прогоне: инструкции проекта — в системном промпте,
  дополнительные папки — рабочие папки чата (вместе с добавленными вручную),
  MCP-инструменты — только разрешённых коннекторов. Чат запоминает
  `projectId`. Выбор обычной папки закрывает проект.
- Удаление проекта не трогает папки и чаты.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Описание проекта файлом в папке (`.mai-code/project.json`) | Едет с папкой, в git | Пути к другим папкам машинозависимы; чужая папка не должна менять коннекторы | Хранится у пользователя |
| Отдельная память проекта | Не смешивается с папкой | Две памяти для одной папки — путаница | Память основной папки |

## Последствия

- Фильтр коннекторов — по имени сервера; переименованный сервер выпадет из
  проекта, пока его не отметить заново.
- Проверки: `scripts/test-projects.mjs` (12), раздел [28] `test-agent-loop`
  (инструкции в промпте, только коннекторы проекта), раздел [40] `test-ui`.
