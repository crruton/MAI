# 0007. Офлайн-дистрибутив с node_modules

- **Статус:** accepted
- **Дата:** 2026-11-04

## Контекст

Текущий TAR содержит исходники, но не `node_modules`. На компьютере без сети
`npm install` не работает. Нужен архив, который распаковывается и запускается.

## Решение

Добавлен скрипт `scripts/make-offline.mjs` (`npm.cmd run pack:offline`):

- собирает `dist/win-unpacked` через `electron-builder --dir` (если сборки нет);
- копирует `node_modules` production-зависимостей и Electron;
- кладёт `start-mai-code.cmd` и `README-OFFLINE.txt`;
- упаковывает в `dist/mai-code-<version>-offline-win-x64.tar.gz`;
- считает SHA-256 и пишет его рядом.

Основной способ для пользователя — portable EXE из `dist/win-unpacked`.
TAR нужен для переноса на машину без установщика и без Node.js.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| TAR с исходниками | Малый размер | Нужен npm и сеть |
| Portable EXE | Один файл | SmartScreen без подписи |
| TAR с node_modules | Полный офлайн | 200+ МБ |

## Последствия

- Архив большой; это ожидаемо.
- Подпись кода не настроена: SmartScreen покажет предупреждение.
- Автообновления нет; новая версия — новый архив.
- `node_modules` нужно собирать на той же ОС и архитектуре.
