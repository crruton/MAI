# 0084. «Запомнить?» после прогона и инструмент ocr

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог F4, F8, F19; продолжение ADR 0026 (память), OCR вложений

## Контекст

- F4: память проекта пополнялась только вручную (`# правило`, панель) или
  когда агент сам вызывал `memory_append`. Уроки из выполненной работы
  терялись.
- F19: OCR был только кнопкой у вложения; агент, встретив скан, мог лишь
  попросить пользователя нажать её.
- F8: ROADMAP уже отмечал скачивание ответа сделанным, экспорт сообщений
  ревизора есть (`role: 'review'` в `export/index.js`) — пункт закрыт без кода.

## Решение

**«Запомнить?» (F4).** После прогона, в котором были правки (инструменты
класса write или delete), в доверенной папке и при `settings.suggestMemory`
(по умолчанию включено) main вызывает `suggestLesson({ request, actions,
answer })` — один короткий запрос к той же модели: «есть ли устойчивый урок
для memory.md — одна строка или НЕТ». `cleanLesson` убирает «Урок:», кавычки,
отбрасывает «НЕТ», пустое и длиннее 240 символов (граница слова для
кириллицы — вручную: `\b` в JS её не видит). Урок приходит окну событием
`memory:suggest`; над полем ввода — плашка «💡 Запомнить: «…»?» с кнопками «В
проект», «Глобально», «Нет», без модального окна. Запись — тот же
`memory:append` (версия артефакта). Выключатель — «Настройки».

**Инструмент `ocr` (F19)** — `tools/ocr.js`, класс read: картинка — текст
тем же движком, что у кнопки вложения (`ocrImage`: движок ОС, Tesseract или
модель MAI, по настройкам OCR); скан PDF — до 10 страниц через `pdftoppm` и
распознавание постранично; без `pdftoppm` — понятный отказ. Текст —
данные (ADR 0053). `read_file` для картинки без зрения и PDF без текста
подсказывает инструмент `ocr`. Выключенный OCR — инструмента нет.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Урок — в каждом ответе агента | Без отдельного запроса | Шум, агент отвлекается от задачи | Отдельный короткий запрос после работы |
| Записывать урок сразу | Без кликов | Мусор в памяти | Только с согласия пользователя |
| OCR скана через модель со зрением | Без движка OCR | Не у всех моделей зрение, дорого на многостраничных | Тот же движок, что у вложений |
