# 0058. Возможности модели и глубина рассуждений

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CC13.1, CC7.11

## Контекст

Про модель приложение знало только размер контекста и (по имени) зрение.
`temperature` убиралась по шаблону `gpt-5…`, глубину рассуждений задать было
нельзя, модель без вызова инструментов получала их и отвечала ошибкой.

## Решение

`electron/lib/capabilities.js` — `modelCapabilities(model, provider)`:

| Флаг | Откуда |
|---|---|
| `tools` | `false` только явно у модели провайдера (иначе агент не сможет действовать) |
| `vision` | как раньше (ADR 0024) |
| `reasoning`, `effort` | у модели или по имени: o1–o9, gpt-5+, gpt-oss — глубина low/medium/high; deepseek-r1/reasoner, QwQ, *-thinking — рассуждения без глубины |
| `temperature` | у модели или по имени (нет у gpt-5+ и o-серии) |
| `transport` | `chat`, `responses` или `auto` |
| `context` | у модели |

Флаги переопределяются в списке моделей провайдера: `models: [{ id, tools,
vision, reasoning, effort: ['low','high'] | false, temperature, transport,
context }]`.

- Запрос: `temperature` и `reasoning_effort` — только если модель их
  поддерживает (`requestOptions`); для Responses API — `reasoning: { effort,
  summary: 'auto' }`. Шлюз не принял `reasoning_effort` — шаг повторяется без
  него, и до конца прогона он не шлётся. Модель без инструментов получает
  запрос без `tools` и уведомление «только отвечает текстом».
- Окно: у поля ввода — «Глубина: по умолчанию / быстро / средняя / глубоко»,
  виден только для модели с глубиной (`models:caps`); выбор запоминается в
  окне и уходит с запросом (`chat:start({ effort })`). Размышления модели уже
  показываются блоком «Размышления».
- После перехода на запасную модель (ADR 0057) возможности пересчитываются.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Узнавать возможности из `/models` шлюза | Точно | Большинство OpenAI-совместимых шлюзов их не отдают | Имя + флаги у провайдера |
| Бюджет токенов вместо уровней | Тоньше | У OpenAI-совместимых — уровни; бюджет — у Anthropic напрямую | Уровни |

## Последствия

- Эвристика по имени устареет с новыми моделями — исправляется флагами у
  провайдера без релиза.
- Проверки: `scripts/test-capabilities.mjs` (10), раздел [24]
  `test-agent-loop` (effort и temperature в запросе, шлюз без
  reasoning_effort, модель без инструментов), раздел [38] `test-ui`.
