# 0069. Браузер агента и разрешения по сайтам

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CW4.1, CW4.2

## Контекст

`web_fetch` читает страницу один раз и без JavaScript: ни поиска на сайте, ни
фильтров, ни форм, ни страниц после входа. Cowork управляет браузером:
открывает, читает, нажимает, заполняет — а пользователь видит, что происходит.
Это же и самый опасный инструмент: от имени пользователя на сайте можно купить,
перевести деньги, ввести пароль на поддельной странице.

## Решение

**Окно.** `electron/lib/browser-agent.js` — `createAgentBrowser({ BrowserWindow })`:
отдельное видимое окно Chromium «Браузер агента — MAI», одно на приложение,
создаётся при первом `browser_open`, закрывается вместе с главным окном.
Постоянная сессия `persist:mai-browser`: вход на сайт, который пользователь
сделал сам в этом окне, сохраняется; с окном приложения и его браузером
сессия не пересекается. Только `http(s)`; новые окна открываются в этом же;
загрузки и запросы разрешений сайтов (камера, геолокация, уведомления)
отклоняются. Модуль не импортирует Electron.

**Инструменты** (`tools/browser.js`): `browser_open(url)`, `browser_read`,
`browser_click(ref)`, `browser_type(ref, text, submit?)`,
`browser_screenshot` (картинка модели со зрением, как в ADR 0068). Снимок
страницы — заголовок, адрес, текст (до 12 000 символов) и до 150 видимых
элементов управления с номерами `[N]`; номера ставит скрипт снимка
атрибутом `data-mai-ref`. Ввод — `insertText` после фокуса, как с клавиатуры;
списки — выбор варианта по тексту.

**Разрешения (CW4.2).**
- Классы: `browser_open`, `browser_click`, `browser_type` — `network`;
  `browser_read`, `browser_screenshot` — `read` (страница уже открыта с
  разрешения).
- Предмет правил — домен: из адреса для `browser_open`, иначе домен текущей
  страницы (`subjectOf(..., browserHost)`). «Да, и не спрашивать» предлагает
  `browser_*(домен)` — одно правило на все действия на сайте.
- «Настройки» → «Браузер агента»: выключатель, «Сайты без вопросов» и «Сайты
  под запретом» (`settings.browserSites`) → правила `browser_*(d)` и
  `browser_*(*.d)` в allow/deny (`browserSiteRules`). Расширение списка
  разрешённых — только администратор.
- **Пароли, коды, карты агент не вводит никогда**: поле опознаётся по типу,
  `autocomplete` (`*-password`, `one-time-code`, `cc-*`) и имени/подписи
  (пароль, CVV, номер карты, IBAN, PIN, SMS-код). Инструмент отказывает и
  показывает окно; агенту сказано попросить пользователя через `ask_user`.
  В снимке такое поле помечено «вводит пользователь».
- **Оплата — только с подтверждения**: у инструмента есть `assess(ctx, args)`;
  `runToolCall` вызывает его после политики. Кнопка «оплатить/купить/
  оформить заказ/pay/checkout…» или отправка формы с паролем/картой →
  вопрос в любом режиме, даже при правиле allow и в «Без вопросов»
  (`source: browser-payment`, рекомендация — отклонить, запомнить нельзя);
  в «Не спрашивать» — запрет. Хук PreToolUse такой вопрос не снимает.
- Текст страниц — данные (ADR 0053): `browser_*` в `DATA_TOOLS`, внушённые
  указания помечают прогон.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Playwright / CDP | Богатый API | Зависимость и отдельный Chromium (~150 МБ) | Chromium уже есть в Electron |
| Расширение для Chrome пользователя | Его входы и куки | Отдельная установка, доступ ко всему браузеру | Позже, как опция |
| `<webview>` в окне приложения | Панель внутри чата | Устаревающий механизм, сложнее изоляция | Отдельное окно проще и надёжнее |

## Последствия

- Локальные адреса (сервер разработки) браузеру доступны, в отличие от
  `web_fetch`: это нужно для проверки своих веб-приложений; разрешение — как
  на любой новый сайт.
- Опознание оплаты и чувствительных полей — эвристика: при сомнении решает
  пользователь, окно у него перед глазами.
- Одно окно на приложение: параллельные чаты с браузером мешают друг другу.
- Проверки: `scripts/test-browser.mjs` (Electron, локальный сервер): поля и
  оплата, снимок с номерами, клик по ссылке, ввод и отправка формы, отказ
  вводить пароль и карту, снимок экрана; через `runToolCall` — разрешённый
  сайт без вопроса, оплата спрашивается всегда и не запоминается, запрет в
  «Не спрашивать», сайт под запретом, правило на домен. `test-ui` [27] —
  настройки браузера.
