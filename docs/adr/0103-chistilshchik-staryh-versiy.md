# 0103. Чистильщик старых версий

- **Статус:** accepted
- **Дата:** 2026-11-23
- **Контекст:** бэклог N7 (запрос пользователя); обновление навыков (ADR 0101), сканер обновлений (ADR 0102)

## Контекст

После обновлений остаются старые копии навыков (`skills/.previous`), длинный
вывод инструментов (`tool-output`), временные папки превью, OCR, распаковки
пакетов и слияния, кеши каталогов, удалённых из настроек, и брошенные рабочие
копии git. Удалять старое сразу после обновления нельзя: если новая версия
сломается, копия нужна для отката.

## Решение

- `cleaner.js` (без Electron): `trackVersion` — `<данные>/version-history.json`
  запоминает, с какого момента работает текущая версия; `isStable` — версия
  проработала `cleaner.stableDays` (3) дня.
- `planCleanup`: старые копии навыков — только при стабильной версии и старше
  `previousDays` (14 дней); `tool-output` старше `outputDays` (7); временные
  папки MAI (`mai-previews`, `mai-code-ocr`, `mai-ocr-*`, `mai-package-*`,
  `mai-merge-*`) старше суток; кеши каталогов маркетплейса, которых нет в
  настройках. Рабочие копии git старше 14 дней — только показываются: в них
  может быть неслитая работа (удалять через `/worktree`). Чужие временные папки
  не трогаются.
- `applyCleanup` удаляет только отмеченное из **свежего** плана и только
  внутри папки данных или временной папки: путь, присланный окном, вне плана
  не пройдёт.
- `/cleanup` — список с размером и возрастом, всё удаляемое отмечено, итог
  «освободится N МБ», «Удалить отмеченное» (admin, журнал аудита).
- После ежесуточного скана обновлений: версия стабильна и можно освободить от
  100 МБ — уведомление «Можно освободить … — /cleanup». Само ничего не удаляет.
- Образы Docker — отдельно, `npm run docker:gc` (хранит последние теги).

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Удалять автоматически | Без кликов | Ошибка правил — потеря данных | Подсказка + подтверждение |
| Удалять старое сразу после обновления | Просто | Нет отката при сбое новой версии | После стабильной работы |
| Удалять и рабочие копии | Больше места | Неслитая работа | Только показать |

## Последствия

- Проверки: `test-cleaner` — версия и стабильность, план (что входит и что нет,
  нестабильная версия), удаление с отказом для пути вне папок и worktree,
  размеры; `test-ui` [60] — окно `/cleanup`, удаление только отмеченного.
