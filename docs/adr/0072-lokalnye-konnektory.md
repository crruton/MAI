# 0072. Локальные коннекторы

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Контекст:** бэклог CW3.3; продолжение ADR 0052 (каталог коннекторов)

## Контекст

Кроме удалённых сервисов (Linear, Notion, GitHub) MAI работает с локальными:
Repowise (индекс кода), Multica (доска задач агентов), Postgres, Vault и
SeaweedFS («Хранилище»). Их состояние и включение были разбросаны по панелям
и окну «Хранилища»; пользователь не видел в одном месте, что подключено.

## Решение

- `electron/lib/local-connectors.js` — `localConnectors({ repowise,
  repowiseEnabled, multica, infra, config })`: из результатов проверок —
  карточки с `status` (`ready` / `off` / `missing` / `error`), подробностью
  (версия, причина) и действием: `toggle` (включить здесь же) или `open`
  (панель `panel:multica`, вкладка «Хранилища» `storage:infra`,
  `storage:repowise`). Модуль не зависит от Electron.
- IPC `connectors:local` (любая роль): `repowise.detect`, `multica.status`,
  `infra.probe` параллельно, у каждой проверки предел 8 с — зависший сервис
  даёт «не настроено», а не вечную загрузку. `connectors:localToggle` (admin):
  пока только Repowise (`settings.repowise.enabled`), остальное включается
  своей настройкой (адреса, ключи).
- «Коннекторы» (`/connectors`): ниже каталога — раздел «Локальные» теми же
  карточками; он подгружается отдельно, чтобы не задерживать каталог.
  «Настроить» открывает окно «Хранилища» сразу на нужной вкладке
  (`boards:open` с `focus: 'tab:infra'`; новое окно читает фокус из адреса).
  В онбординге (фильтр по роли) раздел скрыт.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Обернуть сервисы в MCP-серверы | Единый механизм с удалёнными | Свои серверы на каждый сервис, дублирование готовых инструментов | Карточки поверх существующих проверок дешевле |
| Перенести настройку адресов в карточку | Всё в одном окне | Дублирование формы «Хранилища» | «Настроить» ведёт в готовую форму |

## Последствия

- `multica.status()` синхронный (запуск CLI): пока он идёт, main занят —
  как и в панели Multica.
- Проверки: `scripts/test-local-connectors.mjs` (ничего не настроено, всё
  работает, частично: выключен, без pgvector, запечатан, отказ, проверка не
  успела); `test-ui` [37] — карточки в окне коннекторов, «Включить» Repowise,
  «Настроить» открывает вкладку «Хранилища».
