# 0114. Экспорт навыков каталога в Claude Code, OpenCode и Codex

- **Статус:** accepted
- **Дата:** 2026-11-26
- **Контекст:** [бэклог командной работы](../BACKLOG-TEAM.md) E1.9, каталог (ADR 0111), отдача в Multica (ADR 0113)

## Контекст

Часть команды работает не в MAI, а в Claude Code, OpenCode или Codex. Эти агенты читают
навыки из своих папок в формате `SKILL.md`, том же, что у каталога MAI. Без экспорта
навыки снова копируют руками, и копии расходятся.

## Решение

- **Команда** `npm.cmd run skills:export -- --target claude,opencode,codex` с ключами
  `--dry-run`, `--prune`, `--project <папка>`, `--root <каталог>` и именами навыков.
- **Папки.**

  | Агент | Для пользователя | Для проекта (`--project`) |
  |---|---|---|
  | Claude Code | `~/.claude/skills/<имя>/` | `.claude/skills/<имя>/` |
  | OpenCode | `~/.config/opencode/skills/<имя>/` | `.opencode/skills/<имя>/` |
  | Codex | `~/.codex/skills/<имя>/` | `.codex/skills/<имя>/` |

- **Метка** `.mai-catalog.json` в папке навыка: `managed_by: mai-code`, версия, хэш (тот же,
  что для Multica, ADR 0113). Папка без метки — чужая: `conflict`, не перезаписывается.
  Повтор с тем же хэшем ничего не пишет. `--prune` удаляет только папки с меткой, которых
  нет в каталоге, и только при экспорте всего каталога.
- **Запись** — во временную папку рядом и подмена целиком: прерванный экспорт не оставляет
  навык наполовину. Файлы — с LF.
- **Модуль** `electron/lib/skills-export.js` без Electron. Окна в MAI нет: экспорт нужен
  тем, кто работает не в MAI.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Символические ссылки на каталог | нет копий | на Windows нужны права или режим разработчика; правка в агенте меняет каталог | копия с меткой |
| Плагин Claude Code (`.claude-plugin`) | обновление средствами Claude Code | только Claude Code | один механизм на три агента |
| Перезаписывать любые папки | проще | теряются личные навыки с тем же именем | чужое не трогаем |

## Последствия

- Проще: один каталог — четыре потребителя (MAI, Multica, Claude Code, OpenCode, Codex).
- Сложнее: правка навыка в папке агента перезапишется при следующем экспорте новой версии.
  Править нужно в каталоге.
- Пути папок агентов взяты из их документации и проверены тестом на временном home, а не
  на запущенных агентах.
