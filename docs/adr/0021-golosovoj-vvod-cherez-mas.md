# 0021. Голосовой ввод через локальный MAS

- **Статус:** accepted
- **Дата:** 2026-11-12
- **Контекст:** запрос на кнопку микрофона в поле ввода MAI Code

## Контекст

MAI Code — клиент для работы с кодом. Пользователь попросил диктовать задачу
голосом. Своей модели распознавания речи в MAI Code нет: приложение на Node и
Electron.

Рядом есть MAS — локальный помощник с GigaAM-v3. Он уже умеет принимать WAV и
возвращать текст. Его API работает на loopback с Bearer-токеном.

Нужно решить:

1. Кто выполняет распознавание.
2. Как отправлять звук: потоком или пакетом.
3. Как хранить токен.
4. Что делать, если MAS не запущен.

## Решение

1. **Распознаёт MAS.** В MAI Code модели нет. Это дешевле и не дублирует
   загрузку 215 МБ.
2. **Пакетная отправка.** Окно пишет звук через `AudioContext`, собирает WAV и
   отправляет его в `POST /v1/audio/transcriptions`. Поток WebSocket не
   используется: кнопка нужна для короткой фразы, частичный текст и отмена не
   нужны.
3. **Токен читается с диска.** Главный процесс читает
   `%APPDATA%\MAS\data\api-token`. Пользователь ничего не копирует. Поле в
   настройках нужно только для нестандартной установки.
4. **Настройки в `settings.json`.** Раздел `mas`: `enabled`, `url`, `model`,
   `token`. Токен маскируется в `publicSettings`.
5. **Понятная деградация.** Если MAS не запущен, кнопка показывает сообщение и
   не блокирует ввод. Таймаут проверки — 4 с, расшифровки — 180 с.
6. **Переменные для тестов.** `MAS_API_URL`, `MAS_API_TOKEN`, `MAS_API_MODEL`
   перекрывают настройки.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Своя модель в Electron | нет внешнего процесса | 215 МБ, Python-стек | дублирование MAS |
| WebSocket-поток | текст во время речи | сложнее окно и отмена | фраза короткая |
| `MediaRecorder` и WebM | проще код | MAS не читает WebM | нужен ffmpeg |
| Токен в настройках вручную | явно | лишний шаг | файл уже есть |
| Токен в реестре | привычно | сложнее переносить | файл проще |
| Облачное распознавание | нет локальной модели | данные уходят, нужна сеть | приватность |

## Последствия

- Проще: MAI Code не зависит от Python и ONNX.
- Проще: один контракт MAS для MAI Code и скриптов.
- Сложнее: нужен запущенный MAS. Без него голосовой ввод не работает.
- Сложнее: два процесса и общий токен. Токен надо беречь.
- Риск: порт 8765 занят, MAS взял другой. Снижение — поле «Адрес MAS» и
  строка `PORT=` в журнале MAS.
- Риск: первый запрос ждёт загрузку модели. Снижение — MAS держит модель в
  памяти и запускается при входе в Windows; таймаут 180 с.
- Проверить: собранная версия MAI Code и гарнитура.
- Проверено 2026-11-13: собранная версия 0.1.0 показывает кнопку микрофона и
  раздел MAS в настройках. «Проверить связь» отвечает «MAS 0.2.0: связь есть,
  модель gigaam-v3-e2e-ctc». Запись с гарнитуры не проверена: на машине только
  встроенный микрофон Realtek.
