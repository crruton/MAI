# 0046. Режим «Задача»

- **Статус:** accepted
- **Дата:** 2026-11-21
- **Контекст:** бэклог CW1.1

## Контекст

Агент был настроен на программирование: системный промпт про код, тесты и
git, инструменты repowise. Для задач с документами («собери отчёт из этих
файлов», «сравни договоры») это мешает: модель ищет `AGENTS.md`, предлагает
коммиты и отвечает языком разработчика.

## Решение

У чата есть вид `kind`: `code` (как раньше) или `task`. Переключатель
«Код / Задача» рядом с режимом разрешений.

- `task` — свой системный промпт: уточнять задачу через `ask_user`, сначала
  посмотреть файлы, результат сохранять новым файлом рядом (не перезаписывать
  исходные без просьбы), удалять только `delete_file`, не использовать git,
  в конце — что сделано и какие файлы.
- Инструменты кода (repowise) скрыты. Остальное — то же: файлы, рабочие папки
  (ADR 0045), корзина (ADR 0044), список задач, субагенты, MCP.
- Режим разрешений, правила, хуки и доверие — общие для обоих видов: «Задача» —
  другой стиль работы, а не другие права.
- Без чата переключатель задаёт вид для новых чатов (`settings.defaultKind`);
  у чата вид хранится в сессии (`session.kind`, защищён от перезаписи прогоном).
- Инструкции проекта (`AGENTS.md`) в «Задаче» не требуются, но если они есть в
  доверенной папке, загружаются.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Отдельное приложение для задач | Чистый интерфейс | Два набора настроек, провайдеров и разрешений | Один движок, два вида чата |
| Навык «работа с документами» | Без нового режима | Базовый промпт про код всё равно мешает | Свой системный промпт |
| Определять вид автоматически | Без переключателя | Ошибки определения непредсказуемы | Явный выбор |

## Последствия

- Внешние рантаймы (ADR 0029) вид чата не учитывают.
- Дальше: документы как результат (CW2), панель результатов (CW2.6),
  проекты-задачи (CW1.5).
- Проверки: раздел [20] `test-agent-loop` (промпт и инструменты обоих видов),
  раздел [32] `test-ui`.
