# OCR — распознавание текста на изображениях

Дата актуальности: 2026-11-14.

Страница описывает, как MAI Code достаёт текст из картинки: скриншота, фото
документа, схемы. Решение зафиксировано в [ADR 0023](adr/0023-ocr-cherez-adaptery-dvizhkov.md).

## Зачем

Вложение-изображение попадает в папку проекта, но агент видит только путь и
размер. Без распознавания скриншот с текстом ошибки бесполезен: агент не может
его прочитать. OCR превращает картинку в `.txt` рядом с файлом, и дальше работает
обычный `read_file`.

## Движки

| Движок | Платформа | Сеть | Что нужно | Проверено |
|---|---|---|---|---|
| `winrt` | Windows 10/11 | нет | языковой пакет ОС | да, Windows 11 26200 |
| `vision` | macOS | нет | Xcode Command Line Tools | **нет** |
| `tesseract` | любая | нет | бинарник `tesseract` в `PATH` | **нет** |
| `mai` | любая | **да** | ключ шлюза MAI | **нет** |

Порядок в режиме `auto` — локальные первыми, сеть последней:

| Платформа | Порядок |
|---|---|
| Windows | `winrt` → `tesseract` → `mai` |
| macOS | `vision` → `tesseract` → `mai` |
| Linux | `tesseract` → `mai` |

Если движок не найден, берётся следующий. Если не найден ни один, возвращается
ошибка со списком причин по каждому движку.

## Настройки

Раздел `ocr` в `settings.json`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | выключает OCR целиком |
| `engine` | `auto` | `auto`, `winrt`, `vision`, `tesseract`, `mai` |
| `language` | `ru` | язык распознавания |
| `provider` | `mai` | провайдер для сетевого движка |
| `model` | `hunyuan-ocr` | модель шлюза |
| `maxDimension` | `4000` | большие изображения уменьшаются |
| `scale` | `1` | апскейл перед распознаванием |
| `timeoutMs` | `60000` | таймаут движка |

## Языковой пакет Windows

`Windows.Media.Ocr` распознаёт только те языки, чьи пакеты установлены в системе.
Проверить список:

```powershell
powershell -NoProfile -Command "[Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages | ForEach-Object { $_.LanguageTag }"
```

Если русского языка в списке нет, OCR вернёт ошибку с перечнем доступных языков,
а не подставит английский молча. Установка: Параметры → Время и язык → Язык и
регион → Добавить язык → компонент «Оптическое распознавание символов».

## Форматы

`winrt` читает PNG, JPEG, BMP, GIF, TIFF. WebP, AVIF, ICO и SVG движок Windows не
поддерживает — для них нужен `tesseract` или `mai`. Проверка формата стоит до
запуска процесса, поэтому ошибка понятная, а не «движок вернул ошибку».

## Приватность

Движки `winrt`, `vision` и `tesseract` работают локально: изображение не покидает
машину. Движок `mai` отправляет картинку на сервер шлюза и расходует токены.
Поэтому он последний в порядке приоритета, отключается настройкой
`ocr.engine = "winrt"` (или `"tesseract"`), а результат помечается полем `note`.

## Интерфейс

У изображения-вложения в поле задачи есть кнопка «текст». Она запускает
распознавание и добавляет путь к `.txt` в манифест промпта. Кнопка видна только
для изображений и исчезает, когда текст уже получен.

Пока распознавание идёт, кнопка показывает «…» и заблокирована. Ошибка выводится
всплывающим сообщением, вложение остаётся прикреплённым.

## IPC

| Канал | Что делает |
|---|---|
| `ocr:status` | какие движки доступны, какие языки, что выбрано |
| `ocr:recognize` | распознать вложение, записать `.txt` рядом с файлом |

Мост в рендерер: `window.mai.ocr.status()` и `window.mai.ocr.recognize({ projectDir, path })`.

## Проверка

```powershell
npm.cmd run test:ocr
```

24 проверки без сети: разбор настроек, порядок движков, понятные ошибки, защита
от пути вне проекта, запись `.txt`. Реальное распознавание выполняется только
если локальный движок есть в системе, иначе шаг пропускается.

## Ограничения

- `vision`, `tesseract` и `mai` **не проверены** в среде разработки: macOS и
  tesseract недоступны, живой вызов шлюза не выполнялся.
- Качество зависит от движка и разрешения. Мелкий текст на скриншоте читается
  хуже, чем тот же текст в PDF с текстовым слоем.
- PDF-сканы без текстового слоя не распознаются: OCR работает с изображениями,
  а не с PDF. Сначала нужно извлечь страницы в PNG.
- Сетевой движок ограничен 8 МБ на изображение.
- Распознанный текст обрезается на 200 000 символов.
