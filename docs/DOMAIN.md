# Домен для MAI Code

## Бесплатно и сразу

### GitHub Pages

Адрес по умолчанию: `https://crruton.github.io/mai-code/`.

1. Включите Pages: Settings → Pages → Source: GitHub Actions.
2. Запушьте в `main` — workflow `.github/workflows/pages.yml` опубликует `site/`.

Это бесплатно, но адрес содержит имя пользователя и имя репозитория.

### Бесплатные поддомены

| Сервис | Пример | Условия |
| --- | --- | --- |
| DuckDNS | `mai-code.duckdns.org` | бесплатно, нужен вход и обновление IP |
| is-a.dev | `mai-code.is-a.dev` | бесплатно для open-source, заявка через PR |
| js.org | `mai-code.js.org` | только JS-проекты, заявка через PR |

DuckDNS подходит для VPN и домашнего сервера: выдаёт A-запись на ваш IP.
`is-a.dev` и `js.org` подходят для лендинга, но требуют ревью заявки.

## Свой домен

1. Купите домен у регистратора (`.ru`, `.com`, `.dev` — платно; цена зависит от зоны).
2. Для GitHub Pages создайте в DNS:
   - `CNAME` для `www` → `crruton.github.io`;
   - `A` для apex → IP GitHub Pages (`185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`).
3. В Settings → Pages укажите Custom domain и включите Enforce HTTPS.
4. Положите файл `site/CNAME` с доменом, чтобы он не терялся при деплое.

## Домен для VPN

Для `infra/vpn` нужен публичный IP или DNS-имя, указывающее на сервер:

```
A  vpn.example.com  <публичный IP>
```

Порт `51820/udp` пробрасывается на сервер. Если IP динамический — используйте
DuckDNS и обновляйте запись скриптом.

## Ограничения

- «Бесплатный домен» — это поддомен чужой зоны, а не собственная зона.
- GitHub Pages не подходит для API и WebSocket-бэкенда: только статика.
- HTTPS для своего домена настраивается автоматически только на Pages;
  для VPN-панели и Keycloak нужен reverse proxy с TLS.
