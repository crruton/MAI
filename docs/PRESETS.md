# Пресеты рантаймов: DeepSeek Harness, Hermes, JEV

Пресеты — это готовые команды для внешних агентов. Они лежат в
`electron/lib/runtimes.js` (`RUNTIME_PRESETS`) и появляются в списке
«Рантайм» рядом с моделью.

| ID | Название | Команда | Аргументы | Статус |
|---|---|---|---|---|
| `opencode` | OpenCode | `opencode` | `run --format json {prompt}` | включён |
| `herdr` | herdr | `herdr` | `agent prompt {target} {prompt} --wait` | выключен |
| `claude` | Claude Code | `claude` | `-p {prompt}` | выключен |
| `codex` | Codex CLI | `codex` | `exec {prompt}` | выключен |
| `gemini` | Gemini CLI | `gemini` | `-p {prompt}` | выключен |
| `dsh` | DeepSeek Harness | `dsh` | `run {prompt}` | выключен |
| `hermes` | Hermes | `hermes` | `-p {prompt}` | выключен |
| `jev` | JEV | `jev` | `{prompt}` | выключен |
| `custom` | Своя команда | — | `{prompt}` | выключен |

## DeepSeek Harness (`dsh`)

DeepSeek Harness — агентский CLI от DeepSeek. В Multica он запускается как
`dsh --profile multica --stdio` (ACP-протокол). Для прямого запуска из MAI Code
используется `dsh run {prompt}`.

Требования:

- установленный `dsh` в `PATH`;
- `DEEPSEEK_API_KEY` в окружении;
- профиль dsh, если CLI его требует.

Если ваша версия использует другую команду, измените аргументы в панели
«Рантаймы». Пресет — отправная точка, а не гарантия совместимости.

## Hermes

Hermes — coding-агент Nous Research. Пресет: `hermes -p {prompt}`.
Модель задаётся в конфигурации Hermes, а не в MAI Code.

## JEV

JEV — локальный CLI. Команда `jev {prompt}`. Имя команды зависит от установки;
проверьте `jev --help` и при необходимости поправьте аргументы.

## Как включить

1. Установите CLI и проверьте, что он запускается из терминала.
2. Откройте панель **Рантаймы**.
3. Включите пресет и при необходимости поправьте `command`/`args`.
4. Выберите рантайм в списке рядом с моделью.

Подстановки: `{prompt}`, `{model}`, `{projectDir}`, `{target}`.
Если `{prompt}` нет в аргументах, промпт добавляется последним.

## Ограничения

- Точные команды зависят от версии CLI. Пресет может устареть.
- Вывод нестандартных CLI показывается как текст; JSON-парсер есть только у
  OpenCode.
- Интерактивные подтверждения внутри CLI не поддерживаются: процесс запускается
  в неинтерактивном режиме.
- Секреты (API-ключи) не хранятся в пресете. Используйте переменные окружения.
- JEV и Hermes не проверялись в этой среде; команды помечены как непроверенные.
