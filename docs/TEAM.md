# Профиль команды

Актуально на 26.11.2026. Решение — [ADR 0118](adr/0118-profil-komandy.md).

Профиль команды — один git-репозиторий (или папка), из которого каждый участник получает
общие каталоги навыков, MCP-серверы, инструкции и workspace Multica. Профиль не заменяет
личные настройки: он нижний слой, личное и проектное сильнее.

## Что в профиле

`mai-team.json` в корне репозитория профиля, пример — [examples/team-profile](../examples/team-profile/mai-team.json):

| Поле | Что даёт | Чем перекрывается |
|---|---|---|
| `name` | имя профиля в окне «Доступ» | — |
| `marketplaces` | каталоги пакетов и навыков (ADR 0042, 0111) | каталог с тем же именем в `/packages` |
| `mcpServers` | MCP-серверы; заголовки и `env` — только `${ПЕРЕМЕННАЯ}` | глобальные, пакетные, проектные MCP с тем же именем |
| `agents` | путь к `AGENTS.md` команды внутри профиля | личный глобальный `AGENTS.md` и `AGENTS.md` проекта идут после и сильнее |
| `multica.workspaceId` | workspace Multica по умолчанию | «Workspace по умолчанию» в настройках, `.mai-code/settings*.json` проекта (ADR 0112) |

Секретов в профиле нет. Токен, ключ API или приватный ключ в любом поле или в `AGENTS.md`
команды — профиль не применяется целиком, причина видна в окне «Доступ».

## Подключить

Адрес профиля задаёт организация в `managed-settings.json` (ADR 0038):

```json
{ "teamProfile": { "url": "https://github.com/acme/mai-profile.git", "ref": "main" } }
```

Без файла организации admin может задать то же поле `teamProfile` в настройках MAI
(`%APPDATA%\mai-code\settings.json`) — строкой-адресом или папкой. Настройка организации
сильнее.

## Когда обновляется

- При запуске MAI: сразу применяется кэш, свежая версия скачивается в фоне.
- После входа через Keycloak.
- Вручную: IPC `team:refresh` (роль developer и выше, ADR 0117).

Кэш git-профиля — `%APPDATA%\mai-code\team-profile\`. Ошибка сети не стирает прежний кэш.
`AGENTS.md` команды записывается в `%APPDATA%\mai-code\AGENTS.team.md`.

## Ограничения

- Не проверено с приватным git-репозиторием профиля: клон использует учётные данные git
  на машине.
- Кнопки «Обновить профиль» в окне пока нет — только автоматическое обновление и IPC.
