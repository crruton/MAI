# Документация MAI Code

Это оглавление встроенной документации. Открыть её можно из приложения:
кнопка **📖 Документация** в верхней панели.

## Как читать

- **Обзор** — что умеет приложение и как запустить.
- **Работа с проектом** — доски, память, песочницы, OpenSpec, Multica.
- **Инфраструктура** — установка, Kubernetes, DNS, Keycloak, OpenScion.
- **Процесс** — ADR, бэклог, план развития.

## Правила обновления

1. Новая страница добавляется в `docs/SUMMARY.md`.
2. Ссылки проверяются `npm.cmd run docs:check`.
3. Решение оформляется как ADR, изменение — в `CHANGELOG.md`.
4. Непроверенное явно помечается: «не проверено» или «требует инфраструктуры».
