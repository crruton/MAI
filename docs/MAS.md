# Голосовой ввод через MAS

Актуально на 2026-11-13.

Кнопка микрофона в поле ввода записывает голос и вставляет распознанный текст.
Распознавание выполняет локальный MAS. Своей модели в MAI Code нет.

## Требования

1. MAS 0.2.0 установлен и запущен. Он слушает `http://127.0.0.1:8765`.
2. Файл `%APPDATA%\MAS\data\api-token` существует. MAS создаёт его при первом
   запуске.
3. В настройках MAI Code раздел «MAS — распознавание речи» включён.

Токен читается автоматически. Копировать его в настройки не нужно. Поле
«Токен» нужно только для нестандартной установки.

## Как работает

```
микрофон ─► AudioContext ─► WAV ─► Electron main ─► POST /v1/audio/transcriptions
                                                          │
поле ввода ◄── вставка текста ◄── JSON {"text": "..."} ◄──┘
```

1. Нажатие на кнопку начинает запись. Кнопка краснеет.
2. Повторное нажатие останавливает запись.
3. Главный процесс собирает WAV PCM16 и отправляет файл в MAS.
4. Текст вставляется в позицию курсора. Уже набранное не стирается.

Запись короче 0,6 с отклоняется: вероятность ошибки высока.

Пакетная отправка выбрана вместо потока. Кнопка нужна для короткой фразы:
«проверь тесты», «объясни этот файл». Частичный текст и отмена не нужны.

## Настройки

| Поле | По умолчанию | Значение |
|---|---|---|
| Включено | да | Кнопка отправляет запись в MAS |
| Адрес MAS | `http://127.0.0.1:8765` | Порт из строки `PORT=` в журнале MAS |
| Модель | `gigaam-v3-e2e-ctc` | Любой `id` из `GET /api/v1/models` |
| Токен | пусто | Пусто — читать `%APPDATA%\MAS\data\api-token` |

Кнопка «Проверить связь» вызывает `GET /api/v1/health` и показывает версию,
модель и наличие AudioSocket.

Настройки лежат в `%APPDATA%\mai-code\settings.json`, раздел `mas`.

## MAS на другом компьютере

MAS может работать на сервере, а MAI Code — на ноутбуке. Туннель делает
удалённый порт локальным.

1. Откройте туннель на свободный локальный порт. Порт 8765 обычно занят
   локальным MAS.

   ```bash
   ssh -N -L 18765:127.0.0.1:8765 avnosov@193.141.231.254
   ```

2. В настройках MAI Code укажите «Адрес MAS»: `http://127.0.0.1:18765`.
3. Вставьте токен сервера в поле «Токен»:

   ```bash
   ssh avnosov@193.141.231.254 sudo cat /var/lib/mas/api-token
   ```

   Автопоиск читает только локальный файл. Токен сервера задаётся вручную.
   Пустое поле при следующем сохранении оставляет прежний токен.
4. Нажмите «Проверить связь».

Те же значения задают `MAS_API_URL` и `MAS_API_TOKEN`.

## Переменные окружения

Нужны для тестов и CI. Перекрывают настройки.

| Переменная | Значение |
|---|---|
| `MAS_API_URL` | Адрес MAS |
| `MAS_API_TOKEN` | Токен |
| `MAS_API_MODEL` | Идентификатор модели |

## Форматы

MAS принимает WAV и сырой PCM16 16 кГц. MAI Code всегда отправляет WAV:
`AudioContext` даёт 44,1 или 48 кГц, окно пересчитывает их в PCM16.

Сжатые форматы (WebM, OGG, MP3) MAS не читает. Поэтому окно не использует
`MediaRecorder`, который по умолчанию пишет WebM.

## Ошибки

| Сообщение | Причина | Что делать |
|---|---|---|
| «MAS не запущен» | нет соединения | Запустить MAS |
| «MAS отклонил токен» | токен не совпал | Проверить файл `api-token` |
| «Нет токена MAS» | файла нет | Запустить MAS один раз |
| «MAS не разобрал речь» | пустой текст | Говорить ближе к микрофону |
| «Слишком короткая запись» | меньше 0,6 с | Говорить дольше |
| «Нет доступа к микрофону» | запрет Windows | Разрешить доступ в параметрах |

Таймаут запроса — 180 с. Таймаут проверки связи — 4 с.

## Приватность

- Звук уходит только на адрес MAS. По умолчанию это `127.0.0.1`. При удалённом
  MAS звук идёт через SSH-туннель и не попадает к третьим лицам.
- MAS не пишет звук голосового ввода в базу: файл живёт в памяти запроса.
- Токен не показывается в интерфейсе и не пишется в журнал.
- Модель локальная: сеть не нужна.

## Ограничения

- Нет потоковой расшифровки: текст появляется после остановки записи.
- Нет выбора микрофона: используется устройство по умолчанию Windows.
- Нет языкового выбора: модель определяет язык сама.
- MAS запускается при входе в Windows: в MAS включены «Запускать MAS при
  входе» и «Держать модель загруженной». После входа sidecar уже работает, а
  первая фраза не ждёт загрузку весов.
- Если модель выгружена (флаг в MAS выключен или прошёл простой), первый
  запрос ждёт загрузку весов: 10–20 с в зависимости от запуска.
- Если MAS не запущен, sidecar поднимается около 40 с. Проверка связи в первые
  секунды может ответить «MAS не запущен»; повторите её.
- Одновременные запросы к MAS выполняются по очереди.
