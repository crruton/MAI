# Рантаймы: активация и параллельный запуск

Встроенный агент — один. Внешние агенты (OpenCode, Claude Code, Codex,
Gemini, `dsh`, Hermes, JEV, своя команда) — это **рантаймы**. По умолчанию
включён только OpenCode, остальные выключены, поэтому в списке рядом с моделью
виден только он.

## Почему остальные неактивны

Пресеты создаются выключенными, чтобы приложение не пыталось запустить
неустановленный CLI. Включение не проверяет наличие CLI: проверка выполняется
отдельно и показывает бейдж «CLI найден» / «CLI не найден» / «образ есть» /
«образа нет».

## Как включить

1. Откройте панель **Рантаймы**.
2. Нажмите **Включить** у нужного пресета.
3. Нажмите **Изменить**, если команда или аргументы отличаются от пресета.
4. Выберите рантайм в списке рядом с моделью и отправьте запрос.

После включения рантайм появляется в списке. Выключенные рантаймы показаны с
пометкой «(выкл.)» и недоступны для выбора.

## Можно ли включить несколько сразу

Да. Включите несколько рантаймов — в списке появится пункт
**«Все включённые (N, параллельно)»**. Запрос уйдёт всем включённым рантаймам
одновременно, каждый в своём процессе. Ответы приходят отдельными блоками.

Без этого пункта одновременно выполняется только один рантайм: запуск второго
возвращает ошибку «Рантайм уже выполняется».

Параллельный запуск не объединяет контекст: каждый CLI получает один и тот же
промпт и работает независимо. Файлы проекта общие, поэтому два агента могут
конфликтовать при записи. Для безопасного параллелизма используйте отдельные
worktree или docker-режим.

## Режимы запуска

| Режим | Что делает | Изоляция |
|---|---|---|
| `host` | Запускает CLI на этой машине в папке проекта | Нет; guardrails не применяются |
| `docker` | Запускает образ, папка проекта монтируется в `/workspace` | Процессы, сеть, лимиты; файлы проекта доступны |

Docker-режим:

- `--rm --init`;
- сеть `bridge` (можно изменить);
- `--memory 2g`, `--cpus 2`, `--pids-limit 512`;
- `--cap-drop ALL`, `no-new-privileges`;
- `tmpfs /tmp` 256 МБ;
- переменные `DEEPSEEK_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`,
  `MAI_API_KEY`, `GEMINI_API_KEY` пробрасываются, если заданы.

Образ должен содержать CLI рантайма. MAI Code не собирает такие образы
автоматически.

## Проверка доступности

Кнопка **Рантаймы** при открытии выполняет `runtimes:probe`:

- для `host` — `where`/`which` по имени команды;
- для `docker` — `docker image inspect`.

Если CLI установлен, но не виден, перезапустите приложение: PATH обновляется
только в новых процессах.

## Ограничения

- Вывод нестандартных CLI показывается как текст; JSON-парсер есть только у
  OpenCode.
- Интерактивные подтверждения внутри CLI не поддерживаются.
- Guardrails встроенного агента не применяются к внешним рантаймам.
- `dsh`, `hermes`, `jev` не проверялись в этой среде: пакеты из npm с такими
  именами не являются нужными CLI. См. [PRESETS.md](PRESETS.md).
