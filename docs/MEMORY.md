# Память

Память — это текст, который подмешивается в системный промпт агента. Она
дополняет `AGENTS.md`, но не заменяет его.

## Два уровня

| Уровень | Путь | Когда читается |
|---|---|---|
| Глобальная | `%APPDATA%\mai-code\memory.md` | всегда |
| Проектная | `<проект>/.mai-code/memory.md` | при работе с проектом |

Порядок в промпте: глобальные инструкции → инструкции проекта → глобальная
память → память проекта. Размер ограничен: 6000 символов для глобальной и
12000 для проектной.

## Что писать

- Подтверждённые уроки: «API возвращает 429 без Retry-After».
- Решения: «PNG собираем offscreen-окном, nativeImage не декодирует SVG».
- Ограничения: «Repowise 0.60 иногда не отвечает на initialize».
- Договорённости: «Секреты только в .env, не коммитить».

## Что не писать

- Планы и пожелания.
- Секреты, токены, пароли.
- Временные заметки.
- То, что уже есть в `AGENTS.md`.

## Формат

```markdown
# Память проекта

## Уроки

- 2026-11-04: упакованное приложение теряло первый CLI-аргумент.
  Причина: разная нарезка argv в dev и packaged. Решение: process.defaultApp.

## Решения

- Песочница-папка не является границей безопасности.
```

## Редактирование

Панель **Память** в верхней панели. Кнопка «Открыть папку» показывает файл.
Сохранение пишет оба файла сразу.

## Ограничения

- Память — не база знаний: поиск подстрочный, без embeddings.
- Автоматического «запоминания» нет: только явные записи.
- Длинная память обрезается, поэтому держите её короткой.
- Память не версионируется автоматически; используйте git проекта.
