# Память

Память — это текст, который подмешивается в системный промпт агента. Она
дополняет `AGENTS.md`, но не заменяет его.

## Два уровня

| Уровень | Путь | Когда читается |
|---|---|---|
| Глобальная | `%APPDATA%\mai-code\memory.md` | всегда |
| Проектная | `<проект>/.mai-code/memory.md` | при работе с проектом |

Порядок в промпте: глобальные инструкции → инструкции проекта → глобальная
память → память проекта. Размер ограничен: 6000 символов для глобальной и
12000 для проектной.

## Что писать

- Подтверждённые уроки: «API возвращает 429 без Retry-After».
- Решения: «PNG собираем offscreen-окном, nativeImage не декодирует SVG».
- Ограничения: «Repowise 0.60 иногда не отвечает на initialize».
- Договорённости: «Секреты только в .env, не коммитить».

## Что не писать

- Планы и пожелания.
- Секреты, токены, пароли.
- Временные заметки.
- То, что уже есть в `AGENTS.md`.

## Формат

```markdown
# Память проекта

## Уроки

- 2026-11-04: упакованное приложение теряло первый CLI-аргумент.
  Причина: разная нарезка argv в dev и packaged. Решение: process.defaultApp.

## Решения

- Песочница-папка не является границей безопасности.
```

## Редактирование

Панель **Память** в верхней панели. Кнопка «Открыть папку» показывает файл.
Сохранение пишет оба файла сразу.

## Версии и откат

Каждое сохранение создаёт версию в хранилище артефактов
(`<проект>/.mai-code/artifacts/`, тип `memory`, идентификаторы `memory:project`
и `memory:global`). Повторное сохранение того же текста версию не создаёт:
сравнение идёт по SHA-256 содержимого.

В панели **Память** есть кнопки «Версии проекта» и «Версии глобальной». Список
показывает номер, время, размер и пометку. Действия:

| Кнопка | Что делает |
|---|---|
| «Показать» | загружает текст версии в поле, файл не меняется |
| «Откатить» | пишет текст версии в файл и создаёт новую версию с пометкой |

Откат не удаляет историю: он добавляет версию. Поэтому откат можно отменить
откатом к более поздней версии.

IPC-каналы: `memory:read`, `memory:write`, `memory:save`, `memory:version`,
`memory:restore`. Запись и откат требуют роль `admin`.

## Инструменты агента

Агент работает с памятью двумя инструментами.

| Инструмент | Что делает | Подтверждение |
|---|---|---|
| `memory_read` | читает оба уровня и список версий | не требует |
| `memory_append` | дописывает блок в конец памяти и создаёт версию | требует |

`memory_append` пишет через тот же `saveMemory`, что и панель, поэтому история
версий и откат работают одинаково. Повторный текст не создаёт версию: сравнение
идёт по содержимому. Предел одного блока — 20 000 символов.

В режиме «План» `memory_append` скрыт от модели, `memory_read` доступен.
В режиме «Вручную» запись спрашивает подтверждение, в режиме «Авто» — пишет
без вопроса.

## Ограничения

- Память — не база знаний: поиск подстрочный, без embeddings.
- Автоматического «запоминания» нет: только явные записи.
- Длинная память обрезается, поэтому держите её короткой.
- Версии хранятся только для правок через панель и через `memory_append`.
  Правка файла вручную (редактор, `git checkout`) версию не создаёт — следующее
  сохранение зафиксирует расхождение как новую версию.
- `memory_append` только дописывает. Удалить или переписать блок агент не может:
  для этого есть панель «Память».
